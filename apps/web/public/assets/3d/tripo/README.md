# Tripo Studio 가공본 (2026-10-28 ~ 2026-10-29)

Tripo Studio 유료 플랜으로 생성한 뒤 Blender로 웹 최적화한 GLB 모음이다.
원본 고해상도 마스터는 저장소에 포함하지 않고 별도 작업 공간의 `raw/`에 보관한다.
이 디렉터리의 파일은 텍스처 폭 2048px 이하로 축소하고 실제 크기 기준으로 스케일을 맞춘 웹용 버전이다.

## 출처와 권리

- 생성 서비스: Tripo Studio (유료 플랜, 계정 blue45f@gmail.com)
- 생성일: 2026-10-28 ~ 2026-10-29, 생성 설정: Smart Mesh P2.0 / Quad 25,000 / 텍스처 8k 내보내기
- 용도: ToonStudio 내부 기능(배경, 캐릭터 랩, 소품)에서 사용하는 것을 전제로 한다.
  원본 GLB를 그대로 마켓에서 재판매하지 않는다. 판매용 전환은 별도 약관 재확인이 필요하다.
- 리깅본(스켈레톤 포함 버전)은 이 머지에 포함하지 않았다. 캐릭터 리깅본은 별도 작업 공간의
  `raw/rigged-batch*/`에 있으며 다음 정기 머지에서 반영 범위를 정한다.

## 애니메이션본

- `batch13/toonstudio_nurse_walk.glb` (10.4 MB): 간호사 리깅본에 걷기 프리셋 1종을
  적용해 내보낸 애니메이션 GLB. 애니메이션 1개, skin 1개, 삼각형 수 53,577로
  리깅본과 동일, 노드는 70 → 67로 줄었다. 프리셋 내보내기 비용은 0 크레딧으로 측정됐다.
  나머지 리깅 캐릭터의 걷기 적용은 미결정 상태이다.

## 리깅본 (웹 최적화본)

- `rigged/` 디렉토리에 32종: 마네킹·히어로 베이스 8종(배치 3·7)과
  의상 베이스 24종(배치 12·13·14·17)의 Mixamo 인간형 리깅본을
  전체 파이프라인(텍스처 2048 제한 + 0.5 mm 병합 + 노멀 정리)으로 최적화한 버전.
  합계 약 96 MB(원본 약 470 MB에서 축소), 전종 skin 1개·조인트 65개·노드 70개 유지,
  삼각형 수는 원본 대비 2~11% 감소했다.
- 고해상도 리깅 원본은 작업 공간 `raw/rigged-batch*/`에 별도 보관한다.
- 한계: 조인트 수·스킨 존재는 전종 확인했으나, 병합 후 정점별 가중치 값의
  개별 대조와 인앱 포즈 확인은 아직 하지 않았다.

## 아직 하지 않은 검증

- ToonStudio 앱 내 실제 임포트·배치·카메라 각도·포즈 프리셋 회귀 등 육안 검증은 완료되지 않았다.
  파일 단위 검증(메쉬·삼각형 수·재질·텍스처·크기)만 마친 상태이므로, 인앱 검증 전에는
  배경·캐릭터 기능의 최종 품질로 단정하지 않는다.
- 배경 모듈은 통짜 메쉬라 부위별 편집이 아직 어렵다. Blender 부위 분리는 후속 작업이다.
