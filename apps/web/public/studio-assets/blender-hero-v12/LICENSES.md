# ToonStudio V12 플래그십 히어로 3D 에셋

- 상태: current
- 제작일: 2026-11-14
- 제작자: ToonStudio
- 라이선스: **CC0 1.0** — ToonStudio 오리지널 절차·불리언·베벨 모델링 공개 도메인 에셋
- 라이선스 원문: <https://creativecommons.org/publicdomain/zero/1.0/>

아래 4개 플래그십 히어로 GLB는 Blender 5.2.0 LTS(`blend-ai` MCP 라이브 모델링 + `/mcp:blend-ai:blender_best_practices` 메쉬 무결성 검증 `analyze_mesh_quality: issues_found=false` + `glbforge` `desktop-hero` 프로파일 `100 / 100` 통과)로 직접 조형·베벨·불리언·노멀 스무딩하여 제작했다. 외부 3D 모델·상용 텍스처·제3자 저작물을 일절 포함하지 않는다.

| 파일 | 내용 |
| --- | --- |
| `webtoon-shaper-anime-bust-v12.glb` | 3D 셰이퍼 스타일 웹툰 주인공 두상·아이소켓 불리언·홍채·엔젤링 헤어·스탠딩 칼라 흉상 (4,924 tris, 5 draw calls) |
| `fantasy-runic-sword-altar-v12.glb` | 로판·판타지 각성 룬 대검·팔각 석조 제단·부유 마력 크리스탈 세트 (2,664 tris, 4 draw calls) |
| `modern-cafe-espresso-bar-v12.glb` | 현대물 카페 월넛 카운터·듀얼 그룹 에스프레소 머신·포터필터·글래스 페이스트리 쇼케이스 (1,512 tris, 4 draw calls) |
| `hunter-gate-holo-terminal-v12.glb` | 헌터·아카데미 각성 게이트 포털 링·전술 홀로그램 터미널 콘솔 (2,368 tris, 4 draw calls) |

`thumbnails/*.png` 미리보기 4종(512×512)도 동일 GLB에서 직접 렌더링한 스튜디오 프리뷰이며 동일한 CC0 1.0 조건이다. 바이트 크기와 SHA-256 해시는 [provenance.json](provenance.json)에 기록한다.
