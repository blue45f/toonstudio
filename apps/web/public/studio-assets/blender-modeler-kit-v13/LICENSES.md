- 라이선스 원문: <https://creativecommons.org/publicdomain/zero/1.0/>

아래 8개 모듈러 모델러 플래그십 키트 GLB는 Blender 5.2.0 LTS(`scripts/blender/generate_modeler_kit_v13.py` 재현 파이프라인 + 매니폴드 무결성 검증 `nonManifoldEdges=0, looseVertices=0, zeroAreaFaces=0` + `glbforge` `desktop-hero@1` 및 `mobile-hero@1` 프로파일 전원 `100 / 100` 통과)로 직접 제작했다. 외부 3D 모델·상용 텍스처·제3자 저작물을 일절 포함하지 않는다.
