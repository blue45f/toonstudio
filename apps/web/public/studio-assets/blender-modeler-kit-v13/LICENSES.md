# ToonStudio V13 모듈러 모델러 스타터 키트 3D 에셋

- 상태: current
- 제작일: 2026-11-16
- 제작자: ToonStudio
- 라이선스: **CC0 1.0** — ToonStudio 오리지널 절차·베벨·스컬프트 베이스메시 공개 도메인 에셋
- 라이선스 원문: <https://creativecommons.org/publicdomain/zero/1.0/>

아래 4개 모듈러 모델러 키트 GLB는 Blender 5.2.0 LTS(`blend-ai` MCP 메쉬 무결성 검증 `analyze_mesh_quality: issues_found=false` + `scripts/blender/generate_modeler_kit_v13.py` 재현 파이프라인 + `glbforge` `desktop-hero@1` 및 `mobile-hero@1` 프로파일 `100 / 100` 통과)로 직접 제작했다. 외부 3D 모델·상용 텍스처·제3자 저작물을 일절 포함하지 않는다.

| 파일 | 내용 |
| --- | --- |
| `webtoon-sculpt-head-basemesh-v13.glb` | 웹툰 캐릭터 두상·귀·목·쇄골·페데스탈 클린 쿼드 조형 베이스메시 (1,916 tris, 3 draw calls) |
| `webtoon-modular-arch-window-v13.glb` | 아카데미·로판 반원 부수아르 석조 아치·브론즈 멀리언·단일 압출 창호 모듈 (952 tris, 3 draw calls) |
| `webtoon-spiral-stair-core-v13.glb` | 현대 옥상·판타지 공용 10단 오크 디딤판·건메탈 지주·브라스 나선형 핸드레일 계단 코어 (1,580 tris, 3 draw calls) |
| `webtoon-street-bench-lamp-v13.glb` | 일상·로맨스 공원 티크 슬랫 벤치·주철 프레임·따뜻한 랜턴 가로등 세트 (948 tris, 4 draw calls) |

`thumbnails/*.png` 미리보기 4종(512×512)도 동일 GLB에서 결정론적으로 렌더링한 프리뷰이며 동일한 CC0 1.0 조건이다. 바이트 크기와 SHA-256 해시는 [provenance.json](provenance.json)에 기록한다.
