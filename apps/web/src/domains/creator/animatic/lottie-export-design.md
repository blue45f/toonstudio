# Lottie 내보내기 설계 (v1)

근거: artcraft-features REPORT §1.6 (EffectCraft Lottie 입출력) · 대상: 애니매틱·모션 소재
구현: `studio-animatic-lottie-export.ts` (순수 변환기) + `studio-animatic-lottie-export.test.ts`

## 왜 이 범위인가

애니매틱 문서(`StudioAnimaticDocument`)는 픽셀·오디오를 저장하지 않는
타이밍 문서다. 담고 있는 것은 컷 순서·길이·전환·카메라 키프레임(pan/zoom/이징)·
대사 cue뿐이다. 따라서 Lottie 변환의 본질은 "그림 변환"이 아니라
**타이밍·카메라·불투명도의 무손실 이관**이며, 그림은 호출부가 이미지 바인딩으로
연결한다. 바인딩이 없는 컷도 재생이 끊기지 않도록 단색 플레이스홀더 레이어로
내보낸다 (빈 파일·깨진 refId를 만들지 않는 것이 설계 원칙).

## 변환 표 (확정)

| ToonStudio | Lottie | 비고 |
| --- | --- | --- |
| 문서 fps | `fr` | 1–30 그대로 |
| 전체 길이 | `op` (프레임) | `ip=0`, ms→프레임 반올림 3자리 |
| 컷( segment) | 레이어 1개, `ip/op/st` = 컷 구간 | 겹치지 않음. fade도 시간 구간은 순차 |
| 이미지 바인딩 | 에셋 + 이미지 레이어 `ty:2, refId` | `data:`면 임베드(`e:1`), 아니면 파일명 참조(`u:""`) |
| 바인딩 없음 | 단색 레이어 `ty:1` | 컷 순서별 팔레트 순환, 경고 고지 |
| `panXPercent/panYPercent` | `ks.p` (px) | 렌더러와 동일 식: 중심 + pan% × 컴포지션/100 |
| `zoom` | `ks.s` (%) | `fit × zoom × 100`. fit = min(컴포지션/sourceRect 픽셀) — 렌더러 drawCut와 동일 |
| 앵커 | `ks.a` | 이미지 중심(플레이스홀더는 컴포지션 중심) |
| fade 전환 | `ks.o` 0→기준값 | 전환 길이만큼, 첫 컷 제외 (이전 컷이 없음) |
| 키프레임 `opacity` (확장 필드) | `ks.o` 키프레임 | main 문서에는 필드가 없어 기본 100. 키프레임 편집 확장이 넣으면 자동 반영 |
| 대사·효과음 cue | `markers[]` (`tm`, `cm="화자: 대사"`) | 텍스트 레이어는 폰트 에셋이 필요해 v2. 마커는 lottie-web·bodymovin 모두 보존 |
| 레이어 이름 | `nm` = 컷 라벨 | AE·플레이어에서 컷 식별 |

## 이징 표 (확정)

ToonStudio 샘플러는 구간 이징을 **도착 키프레임**에서 읽고, Lottie는
**시작 키프레임**의 탄젠트(`o`/`i`)로 곡선을 정한다. 변환기는 이징을 한 칸
앞당겨 붙인다 — 이 규칙이 없으면 모든 구간의 이징이 한 구간씩 밀린다.

| ToonStudio 이징 | Lottie `o` | Lottie `i` | 근거 |
| --- | --- | --- | --- |
| linear | (0, 0) | (1, 1) | 대각선 제어점 = 선형 |
| ease-in-out | (0.42, 0) | (0.58, 1) | main 구현은 smoothstep이며 표준 cubic-bezier 근사 |
| ease-in (확장) | (0.42, 0) | (1, 1) | CSS/AE 표준 |
| ease-out (확장) | (0, 0) | (0.58, 1) | CSS/AE 표준 |
| hold (확장) | — | — | 키프레임 `h:1` |
| 미지원 이름 | linear로 대체 + 경고 | | 조용한 왜곡 방지 |

## 범위 밖 (v1에서 변환하지 않고 경고로 고지)

- 오디오: Lottie 표준에 오디오 트랙이 없고 주요 웹 플레이어가 재생하지 않는다.
- vertical-scroll 모드: 연속 스트립 스크롤은 컷 레이어 모델과 달라 컷 단위로 강등 변환.
- pan 전환의 추가 오프셋(전환 중 12%): 렌더러 장식 효과라 카메라 곡선과 분리해 제외.
- sourceRect 픽셀 크롭: fit 배율까지만 반영. 정확한 크롭은 프리컴프(ty:0)가 필요해 v2.
- 회전·스케일 비대칭·마스크·도형·효과: 원본 문서에 해당 데이터가 없다.
- Lottie **가져오기**: EffectCraft는 입출력 모두 있으나, ToonStudio 동선은
  내보내기(웹 배포·협업 전달)가 먼저다. 가져오기는 별도 항목으로 분리한다.

## 재생 가능성 판정

- 변환 결과는 `validateLottieAnimationShape`로 필수 구조(v/fr/ip/op, 레이어
  ip<op, refId→에셋 존재, 키프레임 시간 단조성)를 검사한다.
- 테스트의 최소 샘플러가 위치 키프레임을 실제 보간해 중간 프레임 값을
  검증한다 (샘플 변환이 "파일이 생긴다"가 아니라 "재생하면 움직인다"까지 확인).
- 실제 lottie-web 렌더 육안 확인은 CI/브라우저 단계로 이관한다.

## 후속 배선 (이번 범위 밖)

- 워크스페이스 내보내기 메뉴에 "Lottie JSON" 버튼: 자막 내보내기와 같은
  `downloadBlob(new Blob([json]), "storyboard-lottie.json")` 패턴.
- 이미지 바인딩 자동 구성: 워크스페이스 artwork(캡처 해시→data URL)를
  세그먼트에 매핑해 넘기는 어댑터.
- 모션 소재(효과툰) 변환: 컷 리빌·강조는 Lottie 도형/불투명도로 표현
  가능하나 프리셋별 매핑 표가 별도로 필요해 분리한다.
