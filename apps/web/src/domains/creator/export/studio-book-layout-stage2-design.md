# 단행본 조판 2단계 설계 — 스프레드·부모 페이지·재인쇄 검수

> 상태: 확정 (2026-10-14) · 근거: artcraft-features REPORT §1.4 (DesignCraft 스프레드·부모 페이지)
> 대상 표면: `apps/web/src/domains/creator/export/` 단행본 내보내기
> 기계 판독 모델: `studio-book-layout-stage2-model.ts` (이 문서의 데이터 모델 절이 정본, 모델이 그 구현)
> 1단계와의 관계: 이 문서는 1단계를 대체하지 않는다. 1단계 모델을 import해 확장만 한다.

## 0. 목적과 비목적

- 목적: 연재 회차를 단행본으로 묶을 때 작가가 손으로 하던 세 가지를 자동화한다.
  ① 어느 페이지가 펼침의 왼쪽/오른쪽인지 정하기(스프레드 배치)
  ② 쪽번호·작품명·화 제목을 전 페이지에 같은 규칙으로 찍기(부모 페이지)
  ③ 재쇄 때 바뀐 페이지만 다시 검수하기(재인쇄 검수)
- 비목적: 텍스트 스레딩·단락 스타일 같은 장문 조판(REPORT §2에서 "무관에 가까움" 판정 유지),
  인쇄소용 PDF/X 변환 자체(1단계 내보내기 파이프라인 소관), 책등(스파인) 폭 계산
  (종이 두께·총페이지수 입력이 필요해 3단계 후보로 분리, §6).

## 1. 1단계 모델과의 정합 (고정 계약)

| 1단계 산출 | 2단계에서의 사용 | 재정의 여부 |
| --- | --- | --- |
| `BookTrimSpec` (판형·도련·제본 여백·안전 여백) | 페이지네이션·스프레드·부모 배치의 유일한 지면 입력 | 없음 — 그대로 import |
| `computeBookPageBoxes(spec, side)` | 모든 `BookPageSlot.boxes`의 출처. side는 2A가 확정한다 | 없음 |
| `computeSpreadMediaBox(spec)` | 모든 `BookSpread.media`의 출처 | 없음 |
| `BOOK_TRIM_PRESETS` (신국판·B6·A5) | 프리셋 추가 없음. 판형이 늘면 1단계에서만 늘린다 | 없음 |
| `PdfBox` (pt, 좌하단 원점) | 부모 요소 배치 박스도 같은 좌표계 | 없음 |

정합 규칙: 2단계는 mm를 새로 환산하지 않는다(부모 요소 인셋 1곳만 1단계와 같은
`72/25.4` 상수를 쓴다). 지면 수치가 어긋나면 1단계 함수를 고치지, 2단계에서 보정하지 않는다.

## 2. 단계 분해

### 2A. 스프레드 페이지네이션 — `buildBookPagination`

- 입력: `BookPageInput[]`(id·섹션·회차/화 식별자·콘텐츠 해시) + `BookTrimSpec` +
  `BookPaginationOptions`(제본 방향, 화 시작면, 쪽번호 시작 섹션/값).
- 출력: `BookPagination` = `BookPageSlot[]`(물리 순서·면·쪽번호·스프레드 소속·1단계 박스)
  + `BookSpread[]`(좌/우 물리 인덱스·스프레드 미디어 박스) + 경고 목록.
- 확정 규칙:
  1. 표지·뒤표지는 단면(single)으로 분리하고 스프레드에 넣지 않는다.
  2. 제본 방향이 첫 본문 면을 정한다. 좌철→오른쪽 면, 우철→왼쪽 면. 이후 좌우 교대.
  3. 화 시작면(기본: 첫 본문 면과 같은 쪽)이 어긋나면 백지 1장을 자동 삽입하고
     `chapter-opener-side-adjusted` 경고로 작가에게 알린다(조용히 넣지 않는다).
     `chapterOpenerSide: "any"`면 삽입하지 않는다.
  4. 쪽번호는 시작 섹션(기본 content, chapter-opener 포함)부터 센다. 백지도 번호를
     세되(인쇄 관행) 표지는 세지 않는다. 앞부속(목차·판권)의 로마자 번호는
     부모 템플릿의 `folioFormat`으로 표현하고, 매김 자체는 연속으로 둔다.
  5. 본문이 홀수 장이면 `odd-total-pages` 경고만 남기고 자동 백지를 덧붙이지
     않는다 — 끝맺음(작가 후기·백지·뒤표지 안쪽)은 작가가 정하는 영역이다.
- 사용성 기본값: 작가는 판형(1단계)과 제본 방향만 고르면 된다. 나머지 옵션은
  "고급 조판" 펼침 안에 두고, 기본값으로 전 과정이 끝난다.

### 2B. 부모 페이지(마스터) — `ParentPageTemplate` + `resolveParentElements`

- 개념: InDesign의 부모(마스터) 페이지를 웹툰 단행본에 필요한 만큼만 줄인 것.
  템플릿 = 적용 조건(섹션·면) + 자동 요소 목록. 페이지마다 요소를 손으로 찍지 않는다.
- 자동 요소 6종: `folio`(쪽번호) · `work-title`(작품명) · `chapter-title` ·
  `episode-title`(chapter-title과 같은 해소 규칙, 표기 위치만 다르게 쓰는 별칭) ·
  `rule-line`(머리/꼬리 장식선) · `custom-text`(고정 문구).
- 해소 규칙:
  1. 표지 등 단면 페이지에는 부모 요소를 붙이지 않는다.
  2. 템플릿은 배열 순서가 우선순위다. 앞 템플릿이 같은 `kind+anchor`를 냈으면
     뒤 템플릿의 중복 요소는 버린다. 구체 템플릿(화 시작면)을 일반 템플릿(본문)
     앞에 두는 것이 관례 — 기본 묶음 `DEFAULT_PARENT_TEMPLATES`가 이 순서를 따른다.
  3. 쪽번호가 없는 페이지(folio=null), 숨김 섹션(`hideOnSections`), 빈 제목은
     요소를 만들지 않는다. 특히 백지는 기본 묶음에서 전 요소가 숨겨진다.
  4. 위치는 앵커 6종(상/하 × 바깥/가운데/안쪽)으로만 지정한다. "바깥/안쪽"은
     면에 따라 좌우로 뒤집힌다 — 작가가 좌우 페이지를 따로 만들 필요가 없는 것이
     부모 페이지의 핵심 이득이다. 배치 박스는 1단계 안전 박스를 3등분한 띠 안에서
     계산하고, 폰트·자간 같은 렌더 세부는 내보내기 단계 소관으로 남긴다.
  5. 쪽번호 서식: `arabic`(기본) · `arabic-dash`(- 12 -) · `roman-lower`(앞부속용) · `none`.
- 기본 묶음 3종(본문/화 시작면/앞부속)이면 일반 단행본은 설정 없이 완성된다.
  템플릿 편집 UI는 요소를 켜고 끄는 체크 목록 + 앵커 6칸 선택으로 제한한다
  (자유 좌표 편집은 조판 전문 도구의 영역이라 넣지 않는다 — 복잡도 가드).

### 2C. 재인쇄 검수 — `diffPrintRuns` + `evaluateProofChecks` + `canAdvanceProofStage`

- 판(run) 스냅샷: `PrintRunSnapshot`(판 이름, 구조 해시, 페이지 슬롯 목록).
  구조 해시는 판형·제본 방향·부모 템플릿 묶음을 직렬화한 값으로, 내보내기
  단계가 만들어 스냅샷에 실어 준다. 모델은 해시를 만들지 않고 비교만 한다.
- diff 규칙:
  1. 페이지 동일성은 `inputId`로 판단한다. 콘텐츠 해시·쪽번호·면 중 하나라도
     바뀌면 변경 페이지다(면이 바뀌면 마주 보는 페이지의 부모 요소까지 영향이
     가므로 재검수 대상에 넣는다).
  2. 구조 해시가 다르면 사유를 묻지 않고 전 페이지 재검수를 강제한다.
     바뀌지 않았으면 변경+추가 페이지만이 재검수 범위다.
- 검수 단계: `draft → preflight → proof-review → approved → reprint-ready`.
  전이는 한 단계씩만, `proof-review → preflight` 되돌리기만 예외로 허용한다.
  `approved` 이후 전이는 검수 항목에 `fail`이 하나라도 있으면 막힌다.
- 기계 검수 항목 6종 중 이 모델이 직접 판정하는 것: 펼침 쌍(spread-parity,
  홀수면 warn), 쪽번호 연속성(folio-continuity, 끊기면 fail), 안전 영역 유효성
  (bleed-safe 구조 검사), 변경 범위 안내(changed-pages-only).
  이미지 실측이 필요한 검수(안전 영역 침범 픽셀 검사, 표지·책등 실측)는
  1단계 내보내기 파이프라인의 결과를 같은 `ProofCheckResult` 형태로 합류시킨다
  — 항목 id `parent-consistency`·`cover-spine`을 그 합류 지점으로 예약한다.
- 검수 화면 흐름(후속 UI 단계의 계약):
  1. 판 선택: "초판과 비교"가 기본 켜짐. diff가 없으면 전체 검수 모드.
  2. 재검수 범위가 상단에 문장으로 고정된다. 예: "바뀐 3장만 다시 봅니다" /
     "판형이 바뀌어 전부 다시 봅니다".
  3. 스프레드 단위 넘김 검수. 이미 승인된 무변경 페이지는 건너뛰기 대상이며,
     건너뛴 사실이 검수 기록에 남는다.
  4. fail이 있으면 승인 버튼이 비활성이고, 사유가 해당 스프레드로 바로
     이동하는 링크가 된다.

## 3. 데이터 모델 요약 (타입 정본)

- 2A: `BookBinding` · `BookPageSide` · `BookSectionKind`(10종) · `BookPageInput` ·
  `BookPaginationOptions` · `BookPageSlot` · `BookSpread` · `BookPagination` ·
  `BookPaginationWarning`
- 2B: `ParentElementKind`(6종) · `ParentElementAnchor`(6종) · `FolioFormat`(4종) ·
  `ParentElement` · `ParentPageTemplate` · `ResolvedParentElement` ·
  `ParentResolveContext` · `DEFAULT_PARENT_TEMPLATES`
- 2C: `ProofStage`(5단계) · `PrintRunSnapshot` · `ReprintDiff` · `ProofCheckId`(6종) ·
  `ProofCheckResult`
- 저장 형태: 페이지네이션 결과와 스냅샷은 전부 직렬화 가능한 순수 데이터다.
  프로젝트 저장 포맷에는 입력(`BookPageInput[]` + 옵션 + 템플릿)만 저장하고
  결과는 열 때마다 다시 계산한다 — 계산 결과가 저장본과 어긋나는 사고를 없앤다.

## 4. 경계와 실패 케이스

- 빈 책(입력 0장): 빈 결과 + `empty-book` 경고. 예외를 던지지 않는다.
- 화 시작면 강제와 홀수 경고가 겹칠 수 있다. 둘 다 경고로 공존하고,
  자동 삽입은 시작면 규칙 쪽만 한다.
- 같은 id의 페이지가 중복 입력되면 diff의 동일성 판단이 흔들린다 — 입력
  정규화(중복 id 거부)는 호출자(내보내기 표면)의 책임으로 명시한다.
- 부모 템플릿이 하나도 없으면 자동 요소는 없다. 오류가 아니라 "자동 요소 없음"
  상태이며, 검수 화면이 그 사실을 안내한다.

## 6. 후속 단계 (이 설계 밖)

- 2D UI 배선: 내보내기 표면의 스프레드 미리보기, 부모 템플릿 편집(체크 목록형),
  검수 화면. 전부 이 문서 §2의 계약을 입력으로 삼는다.
- 3단계 후보: 책등 폭 계산(종이 두께표 필요), PDF/X-4 변환, 목차 페이지 자동 생성
  (화 제목·쪽번호는 2A/2B 데이터로 이미 만들 수 있다).
