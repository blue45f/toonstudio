# 엔벨로프 왜곡 설계 — 제목 로고·효과음 레터링용 메시 왜곡

> 대상 항목: "엔벨로프 왜곡 설계" (근거: artcraft-features REPORT §1.1 VectorCraft Envelope Distort, §2 대조 판정 "엔벨로프 왜곡·블렌드 — 없음 — 부분 가치. 제목 로고·효과음 레터링 연출에 한정. 설계 단계로 분리")
> 산출: 이 설계 문서(정본) + 순수 모델 프로토타입 `studio-envelope-distort.ts` + 규칙 고정 테스트 `studio-envelope-distort.test.ts` (전부 같은 폴더)
> 판정 조건: ① 왜곡 메시 모델 확정, ② 적용 대상(텍스트/도형) 확정, ③ 프로토타입 범위 확정 — 아래 §2·§3·§7이 각각 답한다.

## 1. 현재 main 실측 — 왜 새 모델이 필요한가

| 기존 자산 (main 실측) | 성격 | 엔벨로프와 왜 다른가 |
| --- | --- | --- |
| `studio-distort.ts` + `StudioDistortPanel.tsx` | 래스터 역매핑 필터 4종(twirl/ripple/pinch/wave), 픽셀 제자리 변형 | 파괴적·이미지 전용. 텍스트/벡터에 걸 수 없고 해상도에 종속 |
| `studio-puppet-warp.ts` | Delaunay 핀 메시, 삼각형 아핀 | 래스터 이미지 전용. 핀 위상이라 "틀(엔벨로프) 모양에 내용을 맞추는" 개념이 없음 |
| `studio-mesh-warp-liquify.ts` | `StudioMeshWarpGrid` (절대 px 격자) + 리퀴파이 브러시 | 가장 가깝지만 bounds 절대 px라 요소 리사이즈 시 왜곡이 깨지고, 프리셋·정규화 좌표·텍스트/패스 적용·비파괴 필드 개념이 없다. 격자는 재사용하지 않고 좌표 규약만 참고했다 |
| `lettering/studio-text-effects.ts` | TextFx 프리셋 16종 | 전부 채움/외곽선/그림자/그라데이션 — **평면 효과만** (체크리스트 근거 문구 "SFX 레터링은 평면 효과 중심" 실측 확인) |
| `lettering/studio-text-path.ts` | 1차원 베이스라인 경로(arc/wave/circle) | 글자를 선에 얹을 뿐 면(面) 왜곡이 아니다. 글자 자체의 상하가 함께 휘지 않음 |
| `lettering/studio-text-vector-bake.ts` | 텍스트 → SVG path data(M/L/Q/C/Z, opentype.js) | 엔벨로프 확장의 입력단 — 이미 존재하므로 패스 왜곡의 입력 규약을 여기에 맞췄다 |
| `studio-element-model.ts` `TextEl` | `textPath?`, `skewX/Y?`는 있으나 envelope 필드 **0건** (실측) | §6의 필드 추가 명세가 필요하다 |
| `studio-sfx-presets.ts` | SFX 단어는 `createSfxTextConfig`로 **TextEl**을 생성 | 즉 SFX 적용 대상 = TextEl 하나로 귀결된다 (별도 SFX 요소 타입 없음) |

결론: 엔벨로프는 기존 왜곡 3종과 겹치지 않는 네 번째 축이다 — **비파괴 · 정규화 좌표 · 벡터/텍스트 대상 · 틀 기반**. 새로 만들되 새 개념은 "엔벨로프 1개"만 추가한다(복잡도 가드).

## 2. 적용 대상 확정 (판정 ②)

| 대상 | 포함 | 방식 |
| --- | --- | --- |
| **라이브 텍스트 `TextEl`** (대사 제외, 제목·SFX 용도) | ✅ v1 핵심 | 미리보기: 요소 박스를 정규화해 렌더 단계에서 왜곡(§6). 확장(expand): 기존 `bakeTextLineToVectorPath`로 패스화 → `warpEnvelopePathData` |
| **벡터 패스 (path data 문자열)** — 베이크된 로고/도형, 벡터 레이어 패스 | ✅ v1 핵심 | `warpEnvelopePathData(env, data, bounds)` 직접 적용. 입력 규약 = bake 출력(M/L/Q/C/Z 절대 좌표) |
| 이미지 요소 | ❌ 제외 | 퍼펫 워프·메시 워프·디스토트 필터가 이미 담당. 엔벨로프를 걸면 중복 개념이 된다 |
| 말풍선 `BubbleEl` | ❌ 제외 | 형상 시스템(variant/customShapePoints) 소관. 대사 텍스트에 면 왜곡을 거는 수요도 없음 |
| 그룹/다중 선택 | ❌ v1 제외 | 요소 단위 필드로 시작. 그룹은 P2에서 "자식 박스 합집합 기준 일괄 적용"으로 검토만 기록 |

- **좌표 규약**: 텍스트는 요소 박스(`x,y,width,height` — 단, `TextEl.height`가 없어 렌더 박스 높이를 쓴다: `fontSize * lineHeight * 줄수`, 호스트가 계산해 넘긴다), 패스는 베이크 `bounds`(x1..y2 → width/height로 환산, 원점 오프셋은 호출자가 평행이동).
- **textPath와의 관계**: v1에서는 **상호배타**. 엔벨로프가 활성이면 textPath는 렌더에서 무시되고 패널에 "곡선 텍스트와 함께 쓸 수 없어요" 안내를 낸다. 이유: 베이스라인 경로(1D)와 면 왜곡(2D)을 합성하면 글자 예산(경로 길이) 계산이 이중으로 꼬이고, 실사용은 둘 중 하나면 충분하다. 합성은 P2 검토 사항으로만 남긴다.
- **세로쓰기(`vertical: true`)**: 박스 기준 정규화라 그대로 적용된다. 단 프리셋 라벨의 "위/아래"는 박스 기준임을 팁에 명시한다.
- **루비·범위 서식**: 기하만 바꾸므로 영향 없음(베이크 확장 시에는 기존 bake의 보고 규약을 따른다).

## 3. 왜곡 메시 모델 확정 (판정 ①) — `studio-envelope-distort.ts`

### 3.1 데이터 모델

```ts
type EnvelopeDistort = {
  version: 1;
  mode: "preset" | "mesh";
  presetId: string;            // ENVELOPE_PRESETS id | "custom"
  bend: number;                // -100..100
  hDistort: number;            // -100..100 (가로 배율 1 + d/200)
  vDistort: number;            // -100..100 (세로 배율)
  cols: 1..4; rows: 1..4;      // 분할 수 (노드 = (cols+1)×(rows+1), 최대 25개)
  nodes: { dx: number; dy: number }[];  // 행 우선, 오프셋만 저장 (정규화, ±0.6 클램프)
}
```

확정 근거:
- **오프셋만 저장, rest는 인덱스로 유도** (`envelopeNodeRest`): 직렬화 최소 + 폰트/박스 리사이즈에 모양이 비율로 유지된다. `studio-mesh-warp-liquify`가 orig/curr를 절대 px로 중복 저장해 리사이즈에 깨지는 문제의 정반대 선택.
- **격자 상한 4×4**: 레터링은 짧은 단어(1~6자)가 대상이라 25 노드로 충분하고, 노드가 많을수록 초보 사용자의 편집 마찰이 커진다. 부족하면 P2에서 6×6까지 상한만 올린다(모델 변경 없음).
- **정규화·항등·프리셋 패턴**은 `studio-distort.ts`/`studio-text-path.ts` 관례와 동일: `normalizeEnvelope`(미상 프리셋→arch, 범위 클램프, 노드 수 불일치 시 모드별 복구), `isIdentityEnvelope`(렌더 생략 판정), 프리셋은 전부 `normalize`를 통과하는 값만 낸다.

### 3.2 평가(보간) — 쌍삼차 Catmull-Rom 곡면

- `sampleEnvelopePoint(env, u, v)`: 셀 탐색 → 행 4개 u방향 Catmull-Rom → v방향 재보간. 노드 정확 통과 + C1 연속. 격자 밖 팬텀 노드는 가장자리 기울기로 **선형 외삽**한다(복제 클램프는 접선을 꺾어 항등에서도 가장자리가 어긋남 — 실측으로 기각, 모델 주석 참조).
- 쌍선형(`studio-mesh-warp-liquify` 방식)을 쓰지 않는 이유: 격자 경계에서 꺾인 윤곽이 굵은 SFX 글자에서 바로 보인다. 삼각형 아핀(퍼펫)도 같은 이유로 제외.
- `warpEnvelopePoint(env, x, y, w, h)`: px ↔ 정규화 변환 래퍼.
- `envelopeHasFold`: 8×8 샘플 셀 외적 부호 역전 검사 — 차단은 하지 않고 경고만 (§5).

### 3.3 프리셋 10종 + 파라미터

아치(arch) · 윗아치(arc-upper) · 아랫아치(arc-lower) · 볼록(bulge) · 물결(wave) · 깃발(flag) · 상승(rise) · 쥐어짜기(squeeze) · 어안 볼록(fisheye) · 원근(perspective). 일러스트레이터 Warp 옵션 15종 중 웹툰 제목/SFX 실수요만 추렸고, 공식은 전부 자체 작성(표준 사인/방사 함수 — 특정 제품 코드 복사 없음).

- `bend` 부호 반전 = 왜곡 방향 반전(프리셋 함수에 a=bend/100가 선형으로 들어가 보장, 테스트 고정).
- `hDistort/vDistort`: 오프셋 축별 배율(±50%) — "아치인데 좌우로도 벌어지게" 같은 2축 조정을 노드 편집 없이 하게 한다.
- preset 모드의 노드는 **항상 파라미터에서 재생성**된다(파라미터가 정본). 노드를 드래그하는 순간 mesh 모드로 전환되고 presetId는 "custom"이 된다 — 일러스트레이터의 "메시로 변환"과 같은 의미론을 자동 전환으로 단순화.

### 3.4 편집 연산 (전부 불변, 참조 안정성 관례는 puppet-warp와 동일)

`applyEnvelopePreset` · `moveEnvelopeNode`(±0.6 클램프, 없는 인덱스/무변화 시 원본 반환) · `resetEnvelopeNode` · `resetEnvelope` · `resampleEnvelopeGrid`(**해상도를 바꿔도 새 노드 위치에서 곡면이 정확히 유지** — 옛 곡면 샘플로 오프셋 재유도, 테스트로 불변식 고정).

### 3.5 패스 적용

`warpEnvelopePathData(env, data, bounds)`:
- 입력: M/L/Q/C/Z 절대 좌표만. 그 외 커맨드(H/V/상대 등)는 **조용히 근사하지 않고 throw** — 호출자가 "확장 불가" 폴백을 결정한다.
- 직선도 셀 크기를 기준으로 분할한다(긴 윗변이 직선으로 남으면 아치가 안 걸린다). 곡선은 구간 샘플링 후 L 폴리라인으로 출력(직선 1..16, 곡선 4..24 구간, 셀 크기 기준이라 오차는 셀 안에 갇힌다).
- 항등 엔벨로프면 입력 문자열을 **그대로** 반환(재직렬화로 인한 diff 노이즈 방지).
- 출력 좌표 포맷은 `studio-text-path.ts`의 fmt 관례(소수 2자리, 꼬리 0 제거)와 동일 — 결정적 출력(테스트 고정).
- 한계: 폴리라인 근사라 인쇄급 확대에서는 구간 상한(곡선 24)이 드러날 수 있다. P2 확장 단계에서 상한 상향 또는 왜곡된 베지어 제어점 출력을 검토한다(모델 API 변경 없이 출력단만 교체 가능).

## 4. 편집 상호작용 설계

진입점은 하나다: **텍스트 요소 선택 → 텍스트 효과 패널(StudioTextEffectPanel)에 "왜곡" 섹션 추가**. 별도 도구/모드를 만들지 않는다(기존 textPath 섹션과 같은 자리, 같은 패턴).

### 4.1 1단계 — 프리셋 (기본 동선, 단순하게)

1. 섹션을 펼치면 프리셋 칩 10종(미니 미리보기 글리프 + 한글 라벨). 칩 클릭 즉시 적용(라이브 미리보기).
2. 슬라이더 3개: 휘어짐(bend, 양극) · 가로 왜곡 · 세로 왜곡. — 텍스트 패널의 기존 `StudioSliderRow` 재사용.
3. 버튼: "처음으로"(reset) — 항등이면 비활성(StudioDistortPanel 관례).
4. 이 단계까지가 전체 사용자의 대부분. 격자·노드 개념은 노출되지 않는다.

### 4.2 2단계 — 메시 직접 편집 (필요할 때 펼침)

1. "메시 직접 편집" 토글 → 캔버스 오버레이에 격자+노드 핸들 표시 (`StudioPuppetWarpOverlay` 패턴: Konva 네이티브 draggable, `name="envelope-node-handle"`로 스테이지 클릭과 구분).
2. 노드 드래그 → 즉시 mesh 모드 전환 + 상단에 "직접 편집 중" 뱃지(프리셋 칩은 선택 해제 상태로).
3. 노드 더블클릭 = 그 노드만 초기화. 격자 해상도 스테퍼(가로/세로 1~4) — 변경해도 모양 유지(§3.4 resample).
4. 접힘 감지 시 경고 뱃지 "글자가 접혀 겹칠 수 있어요" (차단 아님 — 의도적 겹침 연출을 막지 않는다).
5. Esc/토글 해제 = 오버레이만 닫고 왜곡은 유지(비파괴 필드라 편집 종료 ≠ 적용 확정이 아니다).

### 4.3 확정·해제 (패널 하단, 명시적 동작)

- **"윤곽으로 확장"**: 텍스트 → bake(기존 모듈) → `warpEnvelopePathData` → 패스 요소로 교체(원본 텍스트는 숨김 복제본으로 남기지 않음 — 실행취소로 충분). 폰트 로드 실패(bake ok:false) 시 확장을 막고 사유를 알리며, 비파괴 엔벨로프는 그대로 유지된다.
- **"왜곡 해제"**: `envelope` 필드만 제거, 텍스트/스타일은 무손실 복귀.
- 패스 대상은 확장이 곧 적용이다(패스 자체가 결과물) — 원본 패스 문자열은 요소 히스토리(실행취소)가 담당.

### 4.4 상태·실패 케이스

| 케이스 | 동작 |
| --- | --- |
| textPath 활성 요소에 엔벨로프 적용 | 적용은 허용, 렌더는 엔벨로프 우선 + 패널 안내 문구 (§2) |
| 빈 텍스트/공백만 | 섹션 비활성 + "글자를 입력하면 왜곡할 수 있어요" |
| bake 실패(폰트 없음) | 미리보기는 유지(렌더 왜곡), 확장만 비활성+사유 표시 |
| 저장본에 미상 presetId/깨진 nodes | `normalizeEnvelope`이 복구 — 화면이 깨진 채 열리지 않는다 |
| 노드 25개·패스 분할 상한 | 성능 상한을 모델 상수로 고정 (프리뷰는 프레임당 샘플 수 bounded) |

## 5. 렌더링 배선 명세 (P1 — 이 항목 범위 밖, 계약만 확정)

- 미리보기 렌더: Konva `Path`로 베이크한 글리프를 왜곡해 그리는 것이 정본 경로다(텍스트를 래스터화하면 확대 시 깨진다). 폰트 미로드 등 bake 불가 시에만 래스터 스냅샷 + 메시 샘플 근사로 폴백하고 "미리보기 근사" 상태를 내부 플래그로만 둔다(사용자 문구로 겁주지 않음).
- 요소 이동/회전과 엔벨로프는 직교한다: 엔벨로프는 **로컬 박스 안**에서만 적용되고, 요소 transform(위치/회전/skew)은 그 바깥에서 기존 순서대로 적용된다. skew와 동시 적용 순서는 skew → envelope(로컬) → rotation으로 고정한다.
- 내보내기(PNG/PDF/PSD): 렌더와 같은 패스 경로를 타므로 별도 구현이 없다 — 이것이 래스터 디스토트 대신 벡터 엔벨로프를 택한 핵심 이점.

## 6. 요소 모델 패치 명세 (P1에서 적용, 이 항목은 명세만)

```ts
// studio-element-model.ts TextEl에 1필드 추가 (textPath 옆)
envelope?: EnvelopeDistort; // 엔벨로프 왜곡 — 미설정/항등이면 평면. lettering/studio-envelope-distort 규약.
```

- 선택 필드라 기존 저장본 무손실(마이그레이션 없음). CRDT/직렬화는 `textPath`와 같은 경로로 실린다.
- SFX 생성(`createSfxTextConfig`)은 건드리지 않는다 — SFX 프리셋에 엔벨로프를 묶는 것은 P2에서 프리셋별 기본값(예: 충격 카테고리 = bulge bend 35)으로 별도 항목화한다.
