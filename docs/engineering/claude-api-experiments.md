- 상태: **current** — `codex/claude-api-experiments-20261030` 작업 브랜치의 구현·실측 기록. 운영 배포 완료를 뜻하지 않는다.
- 기준일: 2026-10-30
- 범위: 합성 대사의 번역 API 실험, 회차 진단 화면의 결과 출처·실패 처리, 서버의 예산 오류·불완전 응답 정산.
- 관련 문서: [AI 보조 기능](../features/ai-assist.md), [관리형 AI 운영](../operations/free-ai-runtime.md)

## 1. Max 크레딧을 활용하는 조건

Claude Max의 월별 API 크레딧은 사용자가 연결한 Console 조직에 지급된다. 해당 조직의 키와 워크스페이스가 잔액을 공유하므로, 툰스튜디오에서 추정한 비용만으로 조직 전체의 남은 프로모션 크레딧을 계산할 수 없다. 지급 금액·만료일은 Console의 Promotional credits에서 확인한다.

실험 도구의 비용 상한은 이번 실행의 추정 비용을 통제하는 값이다. 조직 전체 잔액이나 실제 청구액을 보증하지 않는다. 계정의 자동 충전·지출한도 설정은 변경하지 않는다.

이번 검증에서 기존 키의 모델 조회와 실제 Messages 호출은 성공했다. 브라우저 연결 제한으로 Max 구독과 Console 조직 연결, 프로모션 잔액·만료일은 확인하지 못했다. 따라서 아래 금액을 Max 크레딧에서 차감된 확정 금액으로 해석하면 안 된다.

공식 자료: [구독자 API 크레딧](https://platform.claude.com/docs/en/about-claude/api-credits-for-subscribers), [사용량·비용 보고](https://platform.claude.com/docs/en/manage-claude/usage-cost-api)

## 2. 재현 가능한 번역 실험

`pnpm experiment:studio-ai`는 기존 앱의 `buildLocalizeRequest`, `LocalizeSchema`, 결과 정규화·용어집 검사와 공통 비용 계산기를 사용한다. 별도 실험용 번역 프롬프트를 만들지 않는다. 깊이는 `low`이고 줄 수에 따른 출력 한도도 앱과 같다.

합성 fixture는 다음 네 가지다. 실제 원고나 사용자 개인정보는 전송하지 않았다.

| 사례 | 입력과 검증 |
| --- | --- |
| 한국어 → 영어 | 인명·길드명 용어집, 숫자 보존 |
| 한국어 → 일본어 | 인명 표기, 일본어 문자와 정중체 표지 |
| 지시문이 포함된 대사 → 영어 | 대사 속 지시를 번역 자료로 처리하고 줄 구조 유지 |
| 영어 → 한국어 | `{{name}}`와 숫자를 대응하는 원문 줄에서 보존 |

모든 사례에서 JSON·스키마, 줄 수·번호·누락, 목표 언어 문자, 용어집, 기호 보존을 확인한다. 정중체 표지 검사는 고정 fixture의 보조 지표다. 의미 정확도 전체, 번역 자연스러움, 작품 완성도를 평가하는 점수로 일반화하지 않는다.

이 실험은 앱의 실제 요청 생성기와 Anthropic 직접 API를 연결한다. ToonStudio 서버 인증·쿼터·관리형 전환 경로 전체의 E2E 검증은 아니다. 서버 경계와 UI 실패 경로는 별도의 단위 회귀 테스트로 확인한다. 콘티·3D·이미지 입력의 실 API 품질 실험은 이번 실행 범위에 포함하지 않는다.

## 3. 실행과 비용 통제

기본은 API를 호출하지 않는 dry-run이다.

```bash
pnpm experiment:studio-ai --dry-run --model claude-haiku-5-5
```

기존 비밀 저장소의 키를 프로세스 환경에 주입한 뒤 명시적으로 실행한다. 키를 명령 인자나 보고서에 넣지 않는다.

```bash
pnpm experiment:studio-ai --execute \
  --model claude-haiku-5-5 \
  --budget-usd 0.5 \
  --label baseline \
  --report /tmp/toonstudio-ai-baseline.json
```

- 공식 Anthropic API에 순차 호출하며 SDK 자동 재시도는 0회다.
- 요청 전 `확인된 추정액 + 미확정 예약액 + 이번 요청의 최대 비용 추정`을 예산과 비교한다.
- 기본 예산은 $0.50이며 `--budget-usd`로 이번 실행의 상한을 지정한다.
- 사용량 누락, 지원하지 않는 다단계 추론 내역(`iterations`), 알 수 없는 단가·모델 변경, 출력 잘림·거절, 품질 조건 실패, 비용 상한 초과 시 더 호출하지 않는다.
- 중단·시간 초과 등 처리 여부가 불확실한 요청은 최대 비용 예약을 남긴다. 취소를 무료 처리로 간주하지 않는다.
- 입력·응답 전문과 제공자 오류 원문은 보고서에 저장하지 않는다. 요청 ID, 모델, 사용량, 지연 시간, 종료 사유와 검사 결과만 남긴다.

보고서의 `requestHash`는 모델 ID를 제외한 실제 요청을 해시하므로 모델 사이의 동일 입력 여부를 비교할 수 있다. 비용에는 캐시 읽기·쓰기와 1시간 캐시 쓰기 차이를 반영한다. 단가는 공식 가격표의 공개 토큰 가격으로 계산하며 조직별 청구 조정·할인·프로모션 잔액과는 다르다.

## 4. 2026-10-30 실 API 결과

각 모델에 네 fixture를 한 번씩 순차 실행했다. 모델 간 요청 해시가 모두 일치했다. 모든 응답이 완료됐고 자동 검사에 통과했으며 미확정 비용 예약은 0이다.

| 모델 | 통과 | 입력 토큰 | 출력 토큰 | 응답 시간 중앙값 | 추정 USD |
| --- | ---: | ---: | ---: | ---: | ---: |
| Haiku 5.5 | 4/4 | 4,963 | 662 | 2.846초 | $0.0008273 |
| Sonnet 5.5 | 4/4 | 4,963 | 711 | 2.951초 | $0.0170360 |
| Opus 5.5 | 4/4 | 4,963 | 757 | 2.699초 | $0.0349920 |
| 합계 | 12/12 | 14,889 | 2,130 | — | **$0.0528553** |

이 실행에서는 캐시 읽기·쓰기 토큰이 모두 0이었다. 중앙값은 모델별 4회 관측이며 지연 시간 우열을 판단할 통계적 근거는 아니다. 짧은 구조화 번역의 반복 실험에는 Haiku를 먼저 쓰고, 품질 문제가 드러난 동일 fixture를 Sonnet·Opus와 비교할 수 있다. 이 결과만으로 운영 기본 모델을 교체하지 않았다.

실측 원본: [Haiku](experiments/2026-10-30/haiku-baseline.json), [Sonnet](experiments/2026-10-30/sonnet-comparison.json), [Opus](experiments/2026-10-30/opus-production-model.json). 입력과 출력 전문은 없으며 요청 해시·ID와 사용량으로 비교 근거를 남겼다.

## 5. 기능 고도화

### 회차 진단 화면

실제 실행의 실패를 로컬 예시 성공으로 바꾸지 않는다. 오류 안내·명시적 재시도·중단을 제공하고, 탭 전환·대본 변경·패널 닫기 시 요청을 취소해 늦은 응답이 다른 입력에 반영되지 않게 했다.

로컬 결과는 “로컬 예시 · AI 미실행”, 실제 결과는 “AI 작성 제안 · 실측 아님”으로 구분한다. 플랫폼 독자 빅데이터에 접근한다는 주장, 근거 없는 별점·완독률·체류시간·좋아요 수, 작붕 0% 보장을 제거했다. 이전 호출자와의 호환을 위해 숫자 필드는 0으로 정규화하되 화면에서 성과 지표로 표시하지 않는다.

### 서버 예산·불완전 응답

Anthropic의 지출한도 429 및 명시적인 크레딧 부족 400을 일반 속도 제한과 구분한다. 확정 거절 시 무료 후보로만 전환하며 다른 유료 제공자로 자동 우회하지 않는다.

`max_tokens`·`pause_turn`·컨텍스트 한도 종료를 성공으로 집계하지 않는다. 기존 Messages 본문·종료 사유·사용량은 유지하면서 원장에는 실패 상태를 남기고 중복 실행 방지 영수증을 유지한다. 처리된 응답 후 원장 마감이 실패하더라도 불완전 응답을 503으로 바꿔 새 호출을 유도하지 않는다.

### 비용 표시

2026-10-30 공식 가격표에 맞춰 Sonnet 5.5 캐시 읽기, Haiku 5.5 일반·긴 프롬프트 캐시 읽기 단가를 수정했다. 캐시를 포함한 입력이 100,000토큰을 초과하면 Haiku의 긴 프롬프트 단가를 적용한다.

공식 자료: [Anthropic 가격표](https://platform.claude.com/docs/en/about-claude/pricing), [구조화 출력의 예외](https://platform.claude.com/docs/en/build-with-claude/structured-outputs)

## 6. 검증과 운영 반영

관련 Vitest 9개 파일의 기존 185개 테스트와 후속 다단계 사용량 가드 7개 테스트, 총 192개가 통과했다(실험 하네스 파일은 최종 41개 통과). `pnpm harness:verify --base=ce51781982bacc3bf40956c30fec79fe52fcfcdc`도 통과했으며, 변경 lint·Secretlint·아키텍처·파일 크기·Studio 진입 그래프·Web/API 타입 검사를 포함한다. 푸시 시 저장소의 필수 훅을 그대로 실행한다.

2026-10-30 확인한 main CI는 GitHub 계정의 결제 또는 사용 한도 문제로 필수 core·verify 작업이 시작되지 못했다. [확인한 CI 실행](https://github.com/blue45f/toonstudio/actions/runs/40923064425). 필수 검사를 우회하지 않으며 이번 변경은 운영 배포 완료 상태가 아니다.

실험을 위해 운영 환경변수·시크릿·DB 스키마·계정 자동 충전·유료 플랜을 변경하지 않았다. 운영 적용과 프로모션 잔액 확인은 각 실제 계정·배포 기록을 기준으로 해야 한다.
