# 구매 번들 로컬 빌드 검증 — 2026-10-29

상태: **current — 구현 브랜치의 로컬 검증**. 운영 배포 완료나 승인된 main SHA의 릴리스 산출물을 뜻하지 않는다. API와 Web의 실제 종료 코드·범위는 [기계 판독 기록](./build-review.json)에 남겼다.

Web은 14,632개 모듈을 변환하고 production manifest를 생성했다. postbuild의 제3자 고지 생성과 CSP 검증이 통과했다. Studio 번들 구조 검사는 417청크, raw 8,346.7KiB/gzip 2,714.7KiB로 통과했고, 제품 투어 Remotion 청크 검사도 통과했다. 기존 런타임 시작 시간 관측값은 오래됐으므로 새로운 성능 측정으로 사용하지 않았다.

[정적 산출물 대조](./static-artifact-review.json)는 실제 dist의 소품 357파일/80,948,537바이트, 완성 배경 7파일/4,440,353바이트, 가상 장식 4파일/800,020바이트를 public 원본과 SHA로 전수 대조했다. 모두 같은 바이트다. 전체 dist는 19,329파일이며, 현재 R2 media descriptor와 oversized ignore 정책 적용 후 Static Assets 파일 수 상한은 12,024개로 20,000개 안이다. Wrangler의 기본 숨김 파일 제외 전 수치여서 상한으로 기록했다. 이 수치는 원격 R2 quota·객체 존재·사용량 확인이 아니다.

Web 빌드는 소스 동결 뒤 시작했고 빌드 도중 같은 소스를 커밋했다. 따라서 시작 시점 HEAD와 검증 소스 커밋을 따로 기록했다. 이 로컬 dist를 운영 릴리스로 사용하지 않는다. 운영 전환은 필수 CI·정확한 main SHA·승인·롤백 기록을 갖춘 별도 빌드와 API → Web 순서를 따른다. 로컬 API 패키징은 macOS arm64이며 Linux 컨테이너는 검증하지 않았다.

최종 전체 하네스는 동결한 커밋 뒤 실행 중이다. 실제 종료 전에는 전체 통과로 집계하지 않으며 최종 결과는 활용 문서·PR과 함께 갱신한다. 업로드·배포·환경변수·DNS·플랜 변경은 실행하지 않았다.
