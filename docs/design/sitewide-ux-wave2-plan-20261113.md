# 전 페이지 작업 중심 UI/UX 재구성

상태: 2026-11-13 구현·검증 중. 1차 메뉴·시작·마켓 변경은 PR #2780으로 병합됐다. 이 문서는 후속 전 페이지 재구성의 설계이며, 전 기능 성공이나 운영 배포 완료를 의미하지 않는다.

## 화면을 나누는 기준

한 화면에는 한 가지 주 작업을 둔다. 작업이 바뀌면 URL이 바뀌는 화면으로 이동하고, 보조 메뉴·사용 설명·예시 이미지는 이름을 보고 펼친다. 단순히 색과 간격만 바꾸거나 기능을 접어 두고 완료로 세지 않는다. 모바일과 PC의 작업 순서와 메뉴 이름은 같다.

| 진입 | 첫 화면 | 다음 동선 | 보존할 계약 |
| --- | --- | --- | --- |
| 전체 메뉴 | 7개 목적 | 목적 → 해당 기능 | 기존 전체 디렉터리·검색·별칭 |
| 내 공간 | 최근 작업 + 독자/창작/계정 3목적 | 목적 선택 → 관련 목적지만 | role/q·Back/Forward·계정/기기 저장 구분 |
| 설정 | 바꾸려는 설정 5목적 | `?view=display/region/age/data/account` | 기존 해시·검색·설정 저장·탈퇴 확인 |
| 작품 시작 | 이야기/바로 그리기 2선택 | 선택한 방법 전용 화면 → 실제 원고 | 원고 identity·생성 실패·가져오기·최근 작업 |
| 작품 찾기 | 검색 또는 결과 | 조건/정렬 → 작품 → 읽기 경로 | 검색 URL·오류/빈 결과 구분·외부 감상 안내 |
| 마켓 | 구매 검색·상품 | 탐색/판매/가이드 각각의 화면 | 필터·query·에셋 권한·거래 절차 |
| 제작 관리 | 내 프로젝트와 현재 작업 | 화면 전환 메뉴 → 제작 단계 한 화면 | 프로젝트/회차·권한·샘플 격리·복구 |

| 커뮤니티 | 선택한 피드 | 피드 모드 URL → 글/참여 | 쿼리·복귀·권한·작성/전송·오류 |
| 기술 문서 | 제목·설명·본문 | 단일 목차 → 다음 문서 | 모든 문서 주소·현재 위치·인쇄·이어보기 |
| 관리자 | 해당 직무 본문 | 현재 그룹 메뉴 → 작업 | 인증/인가·위험 작업 확인·감사·운영 환경 표시 |

## 드로잉과 전문 편집기

- 원고: 캔버스를 중심에 두고 펜·지우개·선택 등 핵심 도구를 유지한다. 전체 도구는 분류 선택 후 도구를 고른다. 더보기는 원고/그리기/출력/화면 목적별로 나눈다.
- 레이어·선택 속성: 이름이 드러나는 진입점을 제공하고 기존 패널과 명령을 호출한다. 그림 상태·Undo/Redo·렌더러·저장 권위는 원래 경계를 유지한다.
- 브러시 랩: 고르기/조절/입력·엔진/질감·톤을 URL별로 분리한다. 미저장 Workbench는 화면 전환 중 보존한다.
- 3D: 장면/구도·작화/레이어의 3목적으로 속성 진입을 줄인다. 모드 설명이 실제 속성보다 앞서 반복되지 않게 한다.
- 캐릭터: 15개 슬롯을 관련된 3분류로 나눈다. 조작 가능한 슬롯과 기존 결과를 그대로 잇는다.

## 구현 적용과 검증을 구분한다

443개 선언 URL에서 실제 lazy page, 공통 UI와 분기를 추적한다. 직접 수정, 공통 소비 경로 변경, 기존 단일 목적 구조 유지, 별칭, 추가 확인 필요를 구분한다. 공통 헤더 한 개를 바꾼 것을 모든 본문 재설계라고 보고하지 않는다.

모바일390px·태블릿834px·PC1440px에서 주 작업의 첫 노출, 가로 넘침, 44px 조작 대상, 현재 위치, 키보드/초점, 뒤로가기, 오류/빈 결과를 확인한다. 게스트·fixture·실제 계정·GPU 사용 여부와 로컬 저장/외부 파일 다운로드/서버 기록의 증거를 분리한다. API 연결 실패를 데이터 없음으로 표시하지 않는다.
