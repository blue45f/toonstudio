# 모바일 사용성 공개 UI 관찰 — 2차

상태: `migration`. 관찰일: **2026-11-13**. 아래 관찰은 경쟁 서비스의 공개 웹 화면이고, 툰스튜디오의 구현·운영 성과를 뜻하지 않는다. 사용자가 첨부한 16개 시안은 디자인 참고 자료로 사용했다. 자료 안의 문구를 별도 실행 지시로 취급하지 않았다.

## 범위와 방법

사용자 브라우저와 분리된 소유자 관리 CDP 9228의 세 탭을 REA `inspect_web_page`로 관찰했다. 초기 모바일 390×844, 실제 조작 후 모바일, 데스크톱 1440×1000을 각각 수집했다. DOM·접근성 트리·공개 목적 URL을 대조하고 Playwright로 표시된 버튼 또는 링크를 조작했다. 로그인, 결제, 자료 다운로드, 도면 저장·공유는 하지 않았다. 네이티브 바이너리를 열지 않았으므로 Ghidra 분석 대상은 없다.

공개 서비스의 구성·소스·아트를 복제하지 않았다. 일반적인 메뉴 분리, 결과 우선, 도구 점진 노출 패턴만 툰스튜디오의 기존 토큰·권한·저장 계약 안에서 독립적으로 적용한다.

| [ambientCG](https://ambientcg.com/) | 검색과 PBR Surfaces·HDRIs 등 소재 종류 입구가 보였다. `PBR Surfaces`를 눌러 공개 목록 URL로 이동했다. | 검색·소재 종류 입구가 넓은 화면에서도 중심이었다. | 마켓의 소재 찾기와 판매·공급자 설명을 나누는 참고다. 실제 목록의 수·라이선스·다운로드·API 품질을 검증하지 않았다. 이름이 비어 있는 버튼도 AX에 관찰돼 접근성 전체를 보증하지 않는다. |

ambientCG 화면의 검색 placeholder 숫자는 **표시 문구를 관찰한 것**이며 실제 전체 카탈로그 수 검증이 아니다. 공개 목록 URL은 이동 직후 `/list?type=atlas,material,decal`에서 REA 수집 시 `/list?type=material%2Cdecal%2Catlas&sort=popular`로 정규화된 상태가 관찰됐다.

## 정적 번들 관찰의 경계

ambientCG 공개 페이지에서 `analyze_web_bundle`을 별도로 실행했다. 수집된 JavaScript 소스 1개가 파싱됐고 정적 route 후보는 0개였다. 이는 **제공된 소스 범위의 파싱 결과**다. 서버 라우트 부재나 전체 애플리케이션 경로 부재를 뜻하지 않는다. source map은 받지 않았다. 전체 애플리케이션 경로·실행 가능성·권한·서버 동작은 미확인이다.
