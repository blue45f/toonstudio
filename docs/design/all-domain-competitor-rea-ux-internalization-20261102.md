# 보존된 직무·작업공간 추천 작업의 복구와 적용 범위

- 상태: `migration`
- 정리일: 2026-11-03
- 출처: 보존된 Gemini 작업 사본의 미커밋 11파일. 원본은 수정하지 않았다.

## 현재 반영 범위

역할별 작업공간·커맨드바 추천 데이터, 온보딩 직군 필터와 추천 미리보기, 익숙한 도구별 검색 별칭, 비교 패널의 검색·선택 요청을 회수한다. 기존 StudioWorkspaceMenu는 검색 별칭을 사용하므로 도구 이름으로 기존 배치를 찾을 수 있다. 실제 배치 전환은 기존 미저장 변경 확인과 저장 흐름을 유지한다.

커맨드바 추천은 순수 데이터 함수이며 기존 사용자 슬롯과 표시 설정을 자동으로 덮어쓰지 않는다. 직무 프로필은 프로젝트 ACL이 아니며 추천 항목이 서버 실행 권한을 부여하지 않는다.

온보딩과 비교 패널 컴포넌트는 현재 제품 라우트의 실제 소비자가 확인되지 않았다. 회수와 단위 검증을 실화면 통합 완료로 표현하지 않는다. 비교 패널은 선택 요청만 전달하며, 부모가 확인한 현재 작업공간 ID가 일치할 때만 사용 중으로 표시한다. 적용 함수가 없으면 선택 버튼은 비활성이다.

## 비교 자료의 한계

[회수 원장](../evidence/rea-all-domain-competitor-ux-benchmark-20261102.json)의 reportedData는 원 작업자의 자체 보고이다. raw 반환과 원문 해시를 확보하지 못해 실행·수치·해석을 독립 검증하지 않았다. 홈페이지 관찰을 실제 편집 기능 검증으로 확대하지 않는다. 원장의 제품 10개와 원 설계서의 16개 주장은 범위가 달라 전수 검증으로 합산하지 않는다.

[제품 목록](../benchmarks/studio-competitor-registry.json)에 추가한 8개는 후속 공개 자료 조사 후보이며 분석 완료나 기능 호환을 뜻하지 않는다. 제품별 외부 기능 동등성, 모바일 성능, 실제 호환성, 전체 역할의 자동 배치 적용은 이번 작업의 검증 범위가 아니다.

## 검증과 후속 조건

관련 단위 시험과 기존 작업공간 메뉴 회귀로 검색, 선택 요청, 미저장 배치 보호, 사용자 커맨드바 보존을 확인한다. 게시 시 실제 명령과 결과는 PR에 기록한다. 실제 온보딩 라우트 연결과 추천 슬롯 적용은 명시적인 사용자 선택·취소·실패·권한 경계의 화면 검증을 갖춘 후속 작업이다.
