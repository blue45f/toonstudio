# ToonStudio 화면 명료성 개선 시안 — 2026-11-11

상태: **migration**. 정적 경로 원장과 코드 감사는 **current**, 전 화면 계열의 정보 위계와 HTML·이미지 시안은 **target**이다. 공통 셸 변경과 각 경로의 런타임 검증·배포 여부는 따로 기록한다.

## 열어 보기

[`index.html`](./index.html)은 빌드·설치·외부 CDN 없이 여는 독립 디자인 갤러리다. 경로 데이터를 HTML에 포함해 로컬 파일로 열어도 목록 검색이 작동한다. 이미지와 기존 보드는 저장소 내 상대 경로로 읽는다.

- **데스크톱·모바일 시안**: 주요 행동과 작업 대상을 먼저 보여주는 HTML 제안.
- **Starlight / Paper 전환**: 기존 Starlight 의미 색상을 기본으로 두고 밝은 Paper 변형과 배치를 비교한다. 제품의 기본 테마나 사용자 설정을 변경하는 기능이 아니다.
- **전 화면 계열 계약**: 시작·편집·소재·제작·탐색·감상·리서치·학습·커뮤니티·마켓·개인·설정·신뢰·소개·체험·관리자·시스템·호환 경로의 18개 계열에 주 목적, 선택 노출, 복구, 모바일 규칙을 제공한다.
- **441개 주소 원장**: 경로·소스·계열을 검색하고 화면 계열 또는 소스 권위 파일로 필터링한다. 행을 펼치면 해당 계열 계약과 선언 파일·행 번호를 확인한다.
- **기존 A–P · M1–M4 보드**: 원본 SVG 5개 묶음과 기존 갤러리·토큰을 연결한다. 기존 자료의 내용과 상태 표시는 이 작업에서 덮어쓰지 않는다.

로컬 HTTP로 확인하려면 저장소 루트에서 다음 명령을 실행한다. 로컬 읽기 서버만 시작하며 배포·외부 서비스 변경은 하지 않는다.

```bash
python -m http.server 5288 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:5288/docs/design/sitewide-clarity-20261111/`를 연다. 확인 후 `Ctrl+C`로 서버를 종료한다.

## 시각 정체성과 새 구성의 관계

기존 기본 테마는 **Starlight Atelier**다. 이 갤러리는 기존 토큰의 남색 표면과 보라·청록 의미 색상을 기본으로 재사용하고, 장식·설명·관련 없는 CTA가 작업 대상을 앞서지 않게 위계를 단순화한다.

새 [콘셉트 이미지](./clarity-concept-paper.webp)는 밝은 **Paper 변형**이다. 이미지의 밝은 배경을 기본 테마 교체 지시로 해석하지 않는다. 기존 보드와 토큰은 [Starlight 정본 시안 패키지](../starlight-atelier-v2-mockups-2026-11-11/README.md)에서 확인한다.

### 공통 페이지 헤더 규칙

상태: **migration**. `SitePageHeader`를 사용하는 제품 소스 22파일·24개 인스턴스에 공통 규칙을 적용한 코드 변경이며, 모든 주소가 이 헤더를 사용하는 것은 아니다.

- 기본 `size="default"`는 작업형 헤더다. 제목은 24–32px로 적응하고 중립 표면·16–20px 안쪽 여백을 사용한다. 제목·설명·검색·필터·주요 행동의 순서를 유지한다.
- 기본 측면 장식 아트는 데스크톱에서 작은 썸네일로 제공하고 모바일에서는 숨긴다. 실제 조작부를 전달한 `aside`는 이 장식 규칙의 대상이 아니며, 별도 `asideClassName` 지정이 없다면 모바일에서도 표시한다.
- 기본 배너는 명시한 아트와 스크림을 유지하되 내용 높이를 따른다. 240px 이상의 강제 최소 높이를 제거하여 작업 폼·목록을 먼저 만나게 한다.
- 큰 제목·대표 아트·배너 최소 높이는 명시적인 `size="hero"`에 유지한다. 마켓·도움말·소개 등 기존 hero 지정은 자동 변경하지 않는다.
- 검색·필터·행동·aside를 자동으로 접거나 삭제하지 않는다. 렌더된 `data-site-page-header-size` 속성으로 빌드와 브라우저에서 기본/hero 적용을 구분한다.
- 읽기 화면의 두 보조 메뉴는 `감상 후 더 보기`(독서 기록·추천)와 `창작·뷰어 체험`(추가 창작 도구)으로 목적을 구분한다. 공식 감상·이전/다음 회차는 접힌 메뉴 밖에 둔다.

생성 원본은 `/workspace/generated_images/exec-633af697-bcca-486e-92b8-e48eb29a31ee.png`이며 원본을 보존한 채 같은 구성의 WebP 사본을 이 폴더에 저장했다. 생성 이미지는 1536×1024이고 데스크톱·모바일 portrait·리더·편집기 구성을 함께 보여준다. 제품의 문구·버튼·데이터를 이미지로 구현하지 않는다.
