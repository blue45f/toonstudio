## 실제 동선의 잔여

- Create → 바로 그리기가 자동 `uiMode=focus`로 기존 복잡한 화면을 먼저 열던 원인을 수정했다(`7a9a156d28`). 새 기본은 간결한 그리기를 사용하며 저장한 화면 설정과 명시 URL은 보존한다. 계획·빠른 시작·Clarity 정책 50개 및 직접 URL 별칭 18개 단위 검사는 통과했고, 변경한 production 빌드의 실제 기본 진입·설정 존중 검증은 아직 대기다.
- 가상 스튜디오 V5의 두 실행은 완료되지 않았다. 첫 실행의 QA 프록시 캐시 응답 처리 문제를 고친 뒤, 두 번째 실행은 실제 ‘간단한 그리기’ 선택을 생략한 수집기 경로에서 멈췄다. 생성 1회 이후 배치·저장·복원을 실행하지 못했으므로 성공으로 기록하지 않는다.
- 드로잉 r5의 4폭 native 메뉴·저장 창·초점·PC 도움말 28조건 통과와 r3의 실제 두 획·Undo/Redo·기기 저장·정상 종료 후 복원·PNG 결과는 지정 범위의 근거로 재사용한다. 캔버스 위 동기화 칩·협업 도구 동시 노출과 작품 상세 복귀 초점은 별도 잔여다. Root가 r6 V2 실패 시점의 1440px 실제 PNG를 직접 보아 협업 버튼·도움말·채팅의 동시 노출을 재확인했으며 시안 충실도 완료로 처리하지 않는다.
- Graphite 검증기의 Chromium 156 상수는 고정 Playwright 1.65.0의 공식 Chromium 158 메타데이터와 충돌했다. 현재 설치된 고정 의존성의 정확한 버전만 허용하도록 연결하고 기존 156 명시 override도 보존했다(`d670e7495a`). 이 검사는 golden 교체가 아니라 실행마다 흰 화면과 128개 실제 획을 비교한다. 픽셀·알파·SwiftShader 기준은 변경하지 않았고 Node 9건이 통과했다. 로컬 Chromium 154와 새 CI 158의 실제 128건 검증을 혼동하지 않는다.
