기존 [Starlight 밀도 제안](../README.md)의 색·타이포·간격·라운드를 재사용했다. 영상은 새로 생성하지 않고 기존 쇼츠 원본에서 파생한 포스터 4개만 예시로 사용했다. 원본 참고보드와 출처 구분은 [기존 비교 자료](../../comparison/README.md)를 따른다. 이 목업에서 Gemini 원본을 새로 생성하거나 독립 검토했다고 주장하지 않는다.

자료를 찾는 사용자는 제목 다음에 검색·분류·비율을 만나고, 첫 영상의 제목을 확인한 뒤 재생하도록 제안한다. 내 작품 홍보·제작 링크, 활용 안내, 보기 방식, 제작·탐색 참고는 목적이 드러나는 이름으로 다시 찾게 한다. 미리보기 높이는 제한하되 `contain`으로 원본 구도를 유지한다.

전체 204편과 세로 쇼츠 49편은 실제 레지스트리 수이며 시안에는 4편만 예시로 그렸다. 실제 구현에서 전체 기본값·원본 다운로드·품질 메모·재생 실패와 재시도를 유지해야 한다. 실패 영상을 숨기거나 개수를 바꿔 정상처럼 보이는 제안이 아니다.

실제 제품에서는 기존 공통 헤더와 기본 너비를 유지하고, 시안의 안내 띠를 넣지 않는다. 기존 재생 모듈을 재사용하며 이 정적 시안은 Android/Safari 재생 성공이나 운영 배포 증거가 아니다. 후속 구현과 동일 뷰포트·동일 상태의 실제 화면·동작 검증은 별도로 연결한다.
