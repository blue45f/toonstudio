## 적용 전에 확인할 계약

- **스토리 기획:** 실제 8개 필드와 초안 소유자·충돌 처리·저장·내보내기는 유지한다. 단계는 표시 범위만 나누며 직접 이전 항목으로 돌아갈 수 있어야 한다. 모바일 저장 행동과 미저장 상태를 계속 찾을 수 있어야 한다.
- **쇼케이스:** 검색·필터와 결과를 먼저 제공하고 추천의 시각적 매력은 짧은 카드로 유지한다. 검색 조건, 상세에서 돌아온 위치, 참여 기능의 발견 가능성을 보존한다. loading·populated와 오류 화면을 별도로 확인한다.
- **게시 정보:** 선택한 제작 프로젝트와 실패 후 입력을 유지한다. JSON 준비는 이미지 분할·업로드·외부 게시·예약 완료가 아니다. 피드는 별도 목적 이름으로 다시 찾을 수 있어야 한다.
- **PC·모바일 통일성:** 같은 기능 명칭과 저장·복귀 규칙을 쓴다. PC의 비교 미리보기는 유지하고 모바일에는 읽기 쉬운 보조 영역으로 제공한다.

목업의 버튼과 입력은 시각 검토용이다. API·사용자 데이터·실제 저장소를 호출하지 않는다. 예시 작품은 제품의 실제 데이터로 표시하지 않는다. 긴 원고·수업 본문은 작업 목적에 필요한 콘텐츠일 수 있으므로 길이 수치만으로 숨기거나 잘라내지 않는다.

## 검토 근거와 버전

기존 실제 390/1440 작업목록 PNG와 현재 소스를 대조해 신규 상태의 중복 시작 행동을 확인했다. 최근 작업의 이어하기 우선·다른 시작 접기는 기반영이다. 스토리 기획의 연속 8입력, 쇼케이스의 검색 앞 큰 추천 무대·작은 태그, 게시 정보의 입력과 실행 왕복, 학습 상세의 본문 앞 목차·단축키는 새 실제 렌더를 대조할 후속 후보다. 소스 확인과 실제 사용 성공을 구분한다.

버전1은 정적 목업 6장을 렌더했다. 직접 시각 검토 뒤 버전2에서는 PC 쇼케이스 검색의 줄바꿈과 PC 게시 정보의 하단 행동 잘림만 교정했다. 기존 버전1 원본은 로컬 QA `archive-v1`에 보존했다. 나머지 4장은 버전1 바이트를 그대로 사용한다. 모든 PNG의 치수·해시·버전은 [manifest.json](./manifest.json)에 있다.

교정한 PC 검색은 한 줄·44px·center hit, 게시 준비 버튼은 y941–985/1000px·44px·center hit를 정적 렌더에서 확인했다. 이것은 제품 접근성·키보드·저장·Back·성능의 통과를 뜻하지 않는다. 제품 회귀 검증은 실제 구현 후 별도로 수행한다.

기존 로컬 Chromium과 브랜드 자산만 사용했다. 브라우저의 파일 프로토콜 거부 뒤 정책에 명시된 localhost HTTP 허용 경로로 정적 HTML과 알려진 이미지 3개만 제공했다. 브라우저 정책은 변경하지 않았고 외부 origin을 차단했으며 렌더 후 브라우저와 서버를 종료했다. 비용·AI 생성·외부 실행은 없다.

## 시안 충실도·동작 검증 계약

위 3시안과6PNG를 그대로 사용한다. 구현 후 같은 상태의 실제390×844/1440×1000 화면을 나란히 대조하고, 레이아웃·색 의미·간격·타이포·컴포넌트의 일치/의도 차이/미해결을 기록한다. 실제 화면에는 커밋·buildId를, 제안에는 이미지 버전·해시를 붙인다. populated·loading·empty·error·권한 상태를 섞어 비교하지 않는다.

목업의 간소화한 상단 메뉴와 제안 라벨은 실제 공통 셸에 그대로 복제할 요소가 아니다. 공통 셸·내비게이션 보존, 실제 콘텐츠와 의미 색 토큰 사용 등 의도 차이는 이유와 첫 화면 높이·문구·가독성 영향을 명시한다. 저장·뒤로 가기·입력·포커스·키보드·터치·모션 감소는 시각 일치와 별도로 실제 실행한다. 경로 수집이나 자동 접근성 통과만으로 시안 구현 완료를 판정하지 않는다.

현재 이 검토에서 제품 actual 재렌더·기능 검증은 실행하지 않았다. 상세 계약은 [review.json](./review.json)의 fidelityContract에 있다.

기술 도감의 사용자 공유 완료 목업과390/1440px 찾기·지도 PNG4장은 [도감 보존 원장](./atlas/README.md)에 연결했다. 원문3개·배치 예시151개이며 실제 구현·정본154개 전체 검색·성능 검증은 별도다.
