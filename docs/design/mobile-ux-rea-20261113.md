# REA 공개 서비스 관찰과 모바일 동선 적용 · 2026-11-13

- 상태: **migration** — 공개 서비스의 관찰 결과와 ToonStudio의 이번 구현·추가 목표를 구분한다.
- 관련 설계: [모바일 중심 UI/UX 재설계](./mobile-first-ux-20261113.md).
- 대상: [Excalidraw](https://excalidraw.com/), [Kleki](https://kleki.com/)의 로그인하지 않은 빈 작업 화면.
- 범위: 공개 UI·접근성 구조를 읽고 일반적인 사용성 원칙을 독립적으로 적용한다. 코드·아이콘·문구·아트를 복사하지 않는다.

## 1. 실행과 증거

## 2. 직접 관찰한 사실

### Excalidraw

- 화면 아래에 손·선택·그리기·지우개·사각형·화살표·텍스트 **7개 도구**와 추가 도구 버튼이 한 줄로 놓인다.
- 접근성 트리에 선택 도구는 `pressed=true`, 다른 도구는 `hasPopup=menu`, `expanded=false`로 기록됐다. 메뉴 내부 동작은 열어 보지 않았다.
- 실행 취소·다시 실행은 빈 작업에서 `disabled=true`로 남아 있다.
- 위쪽에는 메뉴·라이브러리 입구가 있고, 캔버스 중앙의 빈 상태에 열기·도움말·협업·가입을 배치한다.
- 빈 상태는 브라우저 저장소의 한계와 별도 파일 저장 필요성을 설명한다. 실제 파일 저장과 복구 성공 여부는 확인하지 않았다.

### Kleki

- 활성 레이어 캔버스, 브러시·손·확대/축소·실행 취소/다시 실행, 레이어·파일 입구를 관찰했다.
- 브러시 속성은 크기·불투명도·분산에 모이고 원형·분필·캘리그래피·사각형 4개 radio 중 원형이 선택돼 있다.
- 안정화 선택은 접근성 트리에 닫힌 listbox 입구로 기록됐다.
- 390px 화면에서 속성 패널이 넓은 공간을 차지하고 캔버스가 왼쪽의 좁은 영역에 남아 있다. 이 배치를 모바일 권장안으로 채택하지 않는다.
- 이름 없는 일반 요소가 접근성 트리에 많아 전체 조작 수·키보드 사용성을 그 트리만으로 판정할 수 없다.

| 일반 패턴 | ToonStudio 적용 판단 |

## 4. 첨부 시안과 연결한 구현 범위

사용자 제공 16개 시안은 스타일과 정보 계층의 설계 입력이다. 경쟁 서비스 두 화면을 관찰한 것을 시안 16개 전체의 구현·검증 근거로 확대하지 않는다.

**이번 소스에 구현한 상태:** `/create` 기본 화면의 이야기·그리기 두 선택을 유지하고, 고급 시작 레인·주제/제작 도구·전체 최근 작업은 URL로 구분한 별도 화면으로 옮겼다. 일반 새 작업은 목록 상태와 관계없이 `/create`로 연결한다. query/hash, 브라우저 Back, 이동·복귀 후 제목 초점을 관련 테스트로 확인했다.

**추가 분리 소스 구현:** 기존 `section=pipeline`에 모인 장르 프리셋·이야기 주제·제작 단계·공통 하위 메뉴·아트 안내를 목적별 화면으로 나눴다. `topics`는 이야기 주제, `presets`는 장르 프리셋, `tools`는 제작 단계 도구만 보여 준다. `pipeline` 구주소는 제작 도구 화면으로 계속 읽으며, 각 화면에 작품 시작 복귀와 관련 화면 링크를 둔다. 기본 화면의 보조 링크는 3개를 유지한다. 실제 생성·저장·문서 소유자는 변경하지 않는다. 운영 배포·실화면 검증 완료를 뜻하지 않는다.

## 5. 확인하지 않은 항목

- 두 외부 서비스의 메뉴 펼치기, 편집·저장·내보내기·협업·결제·로그인 동작.
- 두 외부 서비스의 모든 화면·모바일 기기·키보드·스크린리더 접근성 적합성.
- 사용자 이탈률·완료 시간·정량적인 사용성 개선 효과.
- source map, 실행 코드 내부, 전체 route/endpoint 목록, 서버·저장소 권위.
- ToonStudio의 운영 배포·실계정 데이터·실제 펜 입력·원격 저장 성공. 로컬 회귀 테스트와 운영 증거를 분리한다.

## 6. 검증 계획

목적별 콘텐츠의 중복 노출 여부, 기존 `section=pipeline` 호환, query/hash·Back·초점, 실제 캔버스 생성과 저장 실패, 최근 작업 복귀를 검증한다. 390px을 우선해 320px·834px·1440px에서도 가로 넘침과 주요 조작 가림을 확인한다. 실행 결과·CI·main 병합·배포 상태는 최종 변경 보고서에 별도로 기록한다.

2026-11-13 로컬 실행 결과: `CreateStartPage.test.tsx`, `StudioQuickStart.test.tsx` 2파일 **40테스트 통과**. 목적별 내용 분리·호환 주소·query/hash·브라우저 Back·제목 초점, 명시 클릭 전 무생성·한 번 생성·저장 실패 재시도를 포함한다. 문서 Secretlint와 담당 TypeScript 파일 ESLint를 별도로 실행했다. 실제 화면·CI·병합·운영 상태는 이 단위 테스트 수로 판정하지 않는다.
