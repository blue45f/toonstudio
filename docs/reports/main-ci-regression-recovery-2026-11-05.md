## 최소 교정 범위

### 단위 테스트와 실제 소스 경계

분리된 history factory·페이지 사전 검사·BG3D 측정 템플릿 helper까지 따라가도록 경계 검사를 갱신했다.
무손실 검사, 첨부 맵의 준비 순서, 런타임 유효성, 권한·reader metadata, 사용자 레이어 보존 검사는 유지했다.
온보딩 역할 선택은 실제 역할 버튼을 한정하고, 카탈로그 수·추천 페이지 잔여 수는 정본 데이터와 비교한다.
Mirror는 2개 quad·8개 half-edge와 렌더링 삼각형 4개를 함께 검증한다.

번역 검사는 새로 등록된 측정·SKP 키와 분리된 페이지 검사 소비자를 포함한다.
제품에서 참조하지 않는 이전 예산 경고 번역 한 쌍만 제거했다.
메뉴 계약 파일은 빈 줄 하나를 줄여 기존 200줄 기준을 유지했다.
그 외 원고·권한·저장·렌더러 제품 소스는 바꾸지 않는다.

기존 CI 패치는 실제 지원 공급자 3개, 시험용 크레딧 게이트의 명시적 활성화·해제 검증,
헤어 실측 0.0427이 기존 5% 기준에서 실패한다는 판정을 유지한다. 품질 기준을 낮춰 통과시키지 않는다.

### 브라우저 검사와 실행 준비

- GPU 필터의 Vite 설정 로더를 기존 CC0 검사와 같은 `runner`로 지정한다. 기존 플러그인의 `import.meta.resolve`가 CJS 번들에서 손실되는 오류를 교정한다.
- 브러시 검사는 도킹 패널 → 확장 보기 → 해당 팝업의 카탈로그를 사용하고, 시작 안내는 기존 준비 helper로 정상 닫는다.
- 편집기 검사는 프로젝트 홈 대신 `/studio/canvas`로 진입한다. 합성 보기 메뉴의 고급 도구는 실제 펼치기 메뉴를 사용한다.
- 주색은 실제 버튼 → HEX 입력 → 적용 → 도구 색 확인을 통해 바꾼다. React 상태나 문서를 직접 주입하지 않는다.
- 정적 미리보기에 없는 API는 정확한 본인 소유 loopback origin·경로·관측 상태만 별도 진단으로 기록한다.
  티켓 취소는 동일 Request의 관측된 응답 상태·POST·fetch·정확한 취소 오류를 확인한다.
  실제 운영 API 성공, 티켓 발급, 저장·권한 검증으로 표시하지 않는다.
- 소프트 프루핑 테스트 경로를 현재 위치로 교정하고, 야간 행렬의 테스트 파일 존재를 검사한다.
- exhaustive는 기존 Core와 같은 Ubuntu 24.04 전용 SDK 정리·심볼릭 링크 거부·작업공간 비중첩·20 GiB 사전 확인을 재사용한다.
  사용자가 작업하는 폴더나 에셋을 삭제하는 절차가 아니다. 기존 무료 표준 러너와 전체 산출물을 유지한다.
- 장획 검사는 원래 지원하는 로컬 미리보기 시작 옵션을 전달한다.
- AI 품질 CLI는 평가기 단위 검사와 명시적 예시 입력을 실행한다. 행 이름도 `ai-quality-evaluator-contract`다.
  예시 점수는 실제 공급자·모델의 품질 측정이나 유료 AI 실행 증거가 아니다.

### 아직 해결됐다고 표시하지 않는 항목

Graphite의 Linux CI 실측은 채널 차이 최대 3으로 기존 기준 4에 미달했다.
동일 제품 소스의 로컬 단일 실행과 5회 반복은 모두 통과했지만 최대 차이가 4로 경계에 붙었다.
CI의 문서 배율 약 102%와 로컬 105%·샘플 위치·래스터 보간 차이가 있어 원인은 아직 미확정이다.

Living Ink는 Linux CI에서 WebGL2 번짐 종횡비 1.42647이 상한 1.35를 넘고,
WebGPU 입상 잔차 1.43696이 하한 1.5에 못 미쳤다. 동일 소스의 macOS 실제 실행은 기존 기준으로 통과했다.
드라이버·half-float 연산·셰이더 중 원인을 확정하지 않았다. 임계값·기본 잉크 강도·기존 저장 획의 재렌더링은 변경하지 않는다.

채우기 Undo의 초기 18,858픽셀 불일치는 별도 보존했다. 저장 문서에서는 채우기 이미지가 제거되고 원본 획이 복원됐다.
실제 화면도 복원됐지만 초기 검사기가 숨겨진 Konva와 선택 핸들을 읽었다.
이 문제는 원고 history가 실패했다는 증거로 사용하지 않으며, 실제 표시 문서 캡처의 교정 결과를 별도로 확인한다.
최종 교정 후에는 기존 허용치 내로 복원됐다. Undo 잔차 6,612픽셀을 보존하며 픽셀 차이 0으로 표시하지 않는다.
캡처의 내부 대기가 fixture의 원래 게시 기한을 넓히지 않도록 전후 기한을 검사한다.
정확히 4,000ms 이상 걸린 결과는 수락하지 않는 음성 회귀를 포함해 관련 27개 테스트가 통과했다.

최초 화면 검증은 `534ee5b1` 기준 제품 빌드에 묶인다. 이후 다른 세션의 main `8b5bcefa30f9a72149d0dd15ce259c83cc95d2a8`
10파일 변경은 정상 merge로 보존하며, 최종 코드의 타입·회귀·PR CI와 이 선행 화면 검증을 구분한다.

다른 exhaustive lane의 시각·성능·WebGPU 진단 전체가 통과했다는 주장은 하지 않는다.
