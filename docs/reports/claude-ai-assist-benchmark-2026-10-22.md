# Claude AI 보조 벤치마크와 추가 기능 구상 (2026-10-22)

- 상태: **역사 자료** — 관찰 시점(2026-10-22)의 공개 페이지에서 읽은 사실과, 그에 근거한 설계 판단·구상이다. 현재 구현의 정본은 [Claude AI 보조](../features/claude-ai-assist.md)이다.
- 작성일: 2026-10-22
- 방법: 로그인 없이 볼 수 있는 공개 페이지를 읽었다. 유료 기능·내부 동작·성능은 보지 못했다. 가격과 기능은 관찰 시점 값이며 바뀔 수 있다.

## 2. 읽은 것에서 끌어낸 설계 판단

| 관찰 | 우리 판단 | 이번 구현 |
| --- | --- | --- |
| 보내기 전까지 아무것도 전송되지 않는다고 밝힌다(GenToon) | 외부로 나가는 것을 **실행 전에** 눈에 보이게 한다 | `ClaudePreflight`: 처리 경로·전송 내용·비용·실패 정책·원본 보호를 실행 버튼 위에 항상 둔다 |
| 행동마다 크레딧을 적는다(GenToon, LlamaGen) | 우리는 크레딧이 아니라 **사용자 Anthropic 계정에 청구되는 금액**이다. 숫자는 지어내지 않고 상한으로 말한다 | 방식 카드와 실행 줄에 "최대 약 $…". 버튼 이름에도 "(요금 발생)". 단가를 모르는 모델은 "가격을 몰라요" |
| 다시 그리면 크레딧을 쓴다(GenToon) | 다시 실행하는 순간에도 비용이 보여야 한다 | 다시 실행 버튼도 같은 상한을 표시하고 세션 예산 가드가 매번 판단한다 |
| 생성 전에 분해 결과를 보여 준다(LTX) | 되돌리기 어려운 일은 **제안과 실행을 나눈다** | 명령 도우미: 계획을 보여 주고 사용자가 단계를 고르고 눌러야 실행한다 |
| 일관성을 위해 요소를 뽑아 태그한다(LTX), 저장한 캐릭터(GenToon) | 번역에서는 **용어집**이 같은 역할이다. 지켰는지는 모델 말이 아니라 글자를 비교한다 | 번역 도우미의 용어집과 "용어집과 달라요" 표시 |
| 텍스트만 번역하고 미리 보기가 없다(WEBTOON) | 번역은 텍스트만 다루고, **미리 보기·고쳐 쓰기를 앞에 둔다** | 번역 결과가 곧 입력칸이고, 말풍선 폭 점검을 줄마다 보여 준다. 작품에는 복사해야 닿는다 |
| 서비스가 문을 닫은 사례(Dashtoon) | 키와 데이터가 특정 서비스에 묶이지 않는 쪽이 안전하다 | 사용자 키(BYOK)로 Anthropic에 직접 연결한다. 결과는 복사해 가져가며 앱이 저장하지 않는다 |
| MCP 연결 화면이 허용 범위·해제를 설명한다(GenToon) | 연결 화면은 **무엇을 허용하는지**를 먼저 말한다 | 연결 카드 3단계 안내와 실행 전 확인. (MCP 서버 쪽은 이번에 만들지 않았다) |

**따라 하지 않은 것**: "학습에 쓰이지 않는다"는 약속 문구. 그 약속은 Anthropic과 사용자의 계약이 정하는 것이라 우리가 대신 말할 수 없다. 우리는 확인 가능한 사실만 쓴다 — 이 브라우저에서 Anthropic으로 바로 가고 ToonStudio 서버를 거치지 않는다.

## 4. 추가 AI 보조 기능 구상 (아직 만들지 않았다 · **target**)

우선순위는 사용자 가치 ÷ (선행 작업 + 위험)으로 어림한 것이다. 숫자 비용은 Haiku 5.5·Opus 5.5 실측(번역 4줄 약 $0.0009, 대체 텍스트 약 $0.0004~0.0005, 아트 디렉터 약 $0.0023)에서 감을 잡은 것이며 입력 크기에 따라 달라진다.

| 순위 | 구상 | 사용자 가치 | 선행 조건 | 위험·주의 |
| --- | --- | --- | --- | --- |
| 1 | **컷 구성 제안** — 장면 글(스크립트)을 컷 목록(샷 종류·핵심 동작·대사 배치)으로 나눈다 | 막막한 첫 콘티를 빠르게 얻는다. LTX·GenToon이 보여 준 "분해 결과 먼저 보기"와 같다 | 텍스트 입력만 있으면 된다. 결과를 편집기에 넣는 길(템플릿·페이지 추가 명령)은 기존 명령 실행기로 연결 가능 | 컷 수를 모델이 정하므로 상한·검증 필요. 저작물은 사용자 입력만 쓴다 |
| 2 | **말풍선 배치 제안** — 이미지와 대사를 보고 말풍선 후보 영역을 제안한다 | 얼굴·핵심 그림을 가리지 않는 자리를 찾는다 | 아트 디렉터의 좌표 정규화·검증을 그대로 쓴다. 편집기에 말풍선을 만드는 API(`StudioCuttoonEditorHost` 경계) 확인 필요 | 좌표가 틀릴 수 있다 → 제안 오버레이로만 보여 주고 사용자가 확정 |
| 3 | **연속성 점검** — 이전 컷과 현재 컷 두 장을 비교해 의상·헤어·소품 불일치를 찾는다 | 회차가 길수록 사람이 놓치는 오류 | 이미지 2장 입력 UI, 비용 상한이 2배 | 모델이 같은 인물인지 잘못 판단할 수 있다 → 확신도 표시 유지 |
| 4 | **캐릭터 말투 사전** — 인물별 말투 규칙을 저장하고 번역·대사 다듬기에 넣는다 | 번역에서 인물 말투가 흔들리지 않는다 | 로컬 저장소(암호화 보관함 정책 검토). 번역 도우미의 용어집 칸을 확장 | 저장하는 순간 개인정보·저작물이 된다 → 기본은 저장하지 않음 |
| 5 | **회차 요약·예고 문구** — 대사와 컷 설명에서 요약·SNS 홍보 문구 초안을 만든다 | 연재 후 반복 작업을 줄인다 | 텍스트만 | 공개 문구라 사용자가 반드시 검토 |
| 6 | **접근성 일괄 점검** — 여러 페이지를 대체 텍스트로 한 번에 만들고 빠진 곳을 보여 준다 | 회차 전체의 접근성 준비 | 이미지 여러 장 입력과 **합산 비용 상한**·진행률 UI | 장 수만큼 비용이 는다 → 시작 전 합계 확인 필수 |
| 7 | **번역 가져오기·되돌려 쓰기** — 스튜디오 텍스트 레이어를 읽어 번역하고 새 언어 레이어로 쓴다 | 복사·붙여넣기 제거 | 편집기 텍스트 읽기/쓰기 API, **한 번에 되돌리기** | 작품을 바꾸는 쓰기라 별도 승인 설계가 필요하다 |
| 8 | **레퍼런스 정리·태깅** — 올린 레퍼런스에 태그와 한 줄 설명을 붙인다 | 소재 창고 검색 | 이미지 여러 장, 저장 위치 결정 | 저작권 있는 레퍼런스 → 사용자 보관함 범위에서만 |
| 9 | **내 피드백 체크리스트** — 최근 아트 디렉터 지적을 모아 반복되는 습관을 요약한다 | 개인 작업 습관 점검 | 결과 보관 정책(지금은 메모리만) | 모델 학습이 아니라 요약이다 — 문구로 오해가 없게 |
| 10 | **외부 에이전트 연동(MCP)** — 스튜디오 명령 계획을 외부 도구에서 호출 | GenToon처럼 다른 도구 안에서 사용 | 인증·권한 최소화·감사 로그 설계 | 보안 위험이 가장 크다. 설계 문서와 별도 승인 없이는 만들지 않는다 |

## 5. 확인하지 못한 것

- 경쟁 제품의 품질·속도·실제 결과물은 보지 못했다(공개 페이지의 문구만 읽었다).
- 가격은 관찰 시점 표기이고 청구 방식이 서로 달라(크레딧 vs 토큰) 직접 비교하지 않았다.
- LlamaGen의 에이전트형 기능은 자사 표현만 읽었고 동작은 확인하지 못했다.
- 우리 쪽 UX는 자동 시험과 실제 호출(합성 이미지 1장·한국어 4줄)로 확인했다. **사용자 시험(관찰, 인터뷰)은 하지 않았다.** 사용성에 대한 주장은 이 점을 전제로 읽어야 한다.
