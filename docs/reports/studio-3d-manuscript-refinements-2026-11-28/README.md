## 설정화 구도

원고용 캐릭터 17종과 기존 원고 호환 모델 제니퍼를 같은 포즈와 카메라로 불러와 바운딩 박스를 비교했다. 18종 모두 경계가 일치했다. 인덱스와 표시 재질을 기준으로 정점 변형 호출은 전체 6,652,125→548,114회, 후미 단독 1,687,150→29,352회로 줄었다. 숨긴 재질 그룹과 그리기 범위 밖 정점이 설정화 축척에 영향을 주는 경우도 회귀 테스트에 포함했다. 실제 편집기에서 후미의 4방향(1,600×2,192)과 8방향(3,168×2,192) PNG를 저장했다. 모든 칸에서 머리와 발은 1,024픽셀 높이 중 Y=70~953 안에 들고 시점마다 윤곽이 달랐다. ## 모델링 파일 왕복

UV 이음선이 있는 책 표지의 한 면을 매끈하게, 다른 면을 평평하게 설정해 OBJ로 저장했다. Blender 4.3.2에서 다시 열면 이전 파일은 UV 0개와 평면 삼각형 4개였고, 수정 파일은 원본의 사각면 2개·코너 UV 8개·음영 설정을 복원했다. 같은 카메라의 480×325 Cycles 렌더에서 수정 파일과 원본은 RGBA가 일치했다. 편집기에서 OBJ를 다시 열어 내보낸 GLB의 원본 해시, 위치·법선·UV 속성과 삼각형 인덱스도 일치했다. 내부 편집기가 다각면으로 읽을 수 없는 오목·비평면 5각형과 4,097각형은 삼각형 3개와 4,095개로 저장해 다시 열었다. [표지의 UV와 면 음영 전후](obj.jpg)

표지가 흰색으로 보일 때에는 파일의 UV와 편집기 표시를 각각 조사했다. 같은 원고를 정상적으로 읽은 뒤에도 초기 재질이 텍스처 없이 연결되면 체크무늬의 GPU 업로드가 0회였다. 체크무늬 텍스처가 준비된 뒤 재질을 연결하도록 바꾸고, 첫 연결에 유효한 텍스처가 있는지와 닫을 때 해제되는지를 회귀 테스트로 확인했다.
