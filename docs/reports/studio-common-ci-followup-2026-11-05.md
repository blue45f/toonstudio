# 자체 안료 공통 CI 후속 검증

상태: `current` — 2026-11-05 클라우드 후보 검증. 원격 CI 및 병합 완료를 뜻하지 않는다.

## 문제와 수정

기준 main은 `5165e4faf796cebe255460ab38d1c13fde8972c4`이다. 생성된 브라우저 fixture의 절대 경로 import를 Knip이 저장소 모듈로 해석해 `quality:imports`가 실패했다. 실제 페이지 URL에서 fixture URL을 만들고 브라우저 콜백 인자로 전달한다. 제공되는 fixture 바이트와 검사 기준은 그대로다.

재료 엔진과 전체 브러시 soak의 합성 V1 fixture 두 곳은 기본 외부 안료를 사용해 원본 보존 guard에 막혔다. V1 접촉 호환 비교에는 자체 안료 `pigment-latent`를 명시한다. V1 버전, 입력, seed, 조정값, dual/single/noSmudge 비교와 전체 카탈로그 검사는 유지한다. 제품 guard나 권리 프로필은 바꾸지 않는다.

main에 이미 있는 보관 획 회귀를 필수 선택자에 등록했다. `studio-foundation` 소유를 한 번만 배정하고, 한국어·영어 발표 자료의 동적 집계를 918개에서 919개로 맞췄다. 이 세 파일 변경은 보존 커밋 `be1df48ee7d87524749502b1e0fb691e360bca6a`에서 이어졌다.

브라우저 수정 전후 fixture 원본, 제공 JS, 모듈 감사, 23브러시 PNG의 SHA-256이 일치했다. 제공 JS는 499,401바이트이며 SHA-256은 `f65ea1b9c7bf17f7001754e1d3cea2c2e21f2336ff9e7d2fc873d5cba20725ff`이다. 정적 진입 그래프는 19.52 MiB로 기존 허용 19.54 MiB 안이다.

머신 판독 근거는 [검증 요약](../qa/evidence/2026-11-05-studio-common-ci.json)에 남겼다. 전체 앱 생산 빌드, 물리 GPU·펜, 운영 배포, 원본 Mixbox와 출력 동등성은 이 후속의 검증 범위에 포함되지 않는다. 실제 브라우저는 SwiftShader를 사용했다.

## 별도로 남은 작업

이 변경은 a7 원격 후속의 WebGL1·sketch 보존 통합, 768·1023px 원본 보관 안내 버튼 가림, 의미 감사 PR #2723, 타입 검사 자원·라이선스 PR #2724를 완료한 것으로 간주하지 않는다. 원본 UX 커밋 `85975aee72b48386ce985f42b3462927344d6b6b`와 승인 PNG 바이트는 미복구 상태이며, 승인 시안 충실도도 확인되지 않았다.

PR은 draft로 게시하고 정확한 head의 필수 CI와 최신 main을 확인한 뒤 조정된 순서로 병합한다. 이 검증에서 추가 main 병합, 되돌리기, 운영 환경 변경은 실행하지 않았다.
