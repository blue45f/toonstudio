## 동작과 소비 경로

기본 `/studio/space`, `/studio/p/:projectId/space`는 `StudioOffice2dCanvas → Office2dRuntime → Office2dRenderer`를 사용한다. 기존 앞 착석 자세에는 웃음·대화 전신 프레임이 있지만, 서 있는 배우는 웃음 이모지를 띄워도 중립 얼굴을 유지했다. 같은 8직군의 의상·머리 모양을 참조한 전신 프레임을 추가해 이 차이를 줄인다.

정면에서 완전히 멈추고 다른 제스처가 없는 배우에게만 기존 보행 몸체 대신 새 전신 표정을 한 번 그린다. 발 접지·호흡·기울기·투명도는 기존 변환을 공유하고, 모자·헤드폰 등은 새 머리 기준점, 안경·선글라스는 별도의 눈 기준점에 맞춰 표시한다. 걷기·보행 관성·다른 방향·착석·제스처 또는 누락/잘못된 크기의 표정 이미지는 기존 몸체로 돌아간다.

활성 웃음이 대화보다 우선하며 만료 후 대화 또는 중립으로 복귀한다. 대화와 웃음은 각각 네 프레임을 순환한다. 동작 줄이기 설정은 정적 표정을 선택한다. 새 시트는 첫 화면 필수 이미지 뒤에 로드한다.

## 생성과 보존

`apps/web/public/assets/virtual-studio/office-standing-expressions-v1/source-originals/`에 8직군 PNG 원본을 보존한다. 각 시트는 1536×1024, 4열×2행이며 대화 4개와 웃음 4개로 구성한다. 내장 `image_gen`에 기존 `office-cast-v2`의 같은 직군 보행 이미지를 참조했다. 외부 API 키나 운영자 유료 추론 경로를 사용하지 않았다. 생성 도구가 모델명을 보고하지 않으므로 특정 모델·버전을 주장하지 않는다.

실제 요청은 직군별 `*-prompt.txt`, 원본과 표시용 파일의 바이트 수·SHA-256·참조 출처는 `manifest.json`에 기록한다. 이 기록은 참조 자산에 새로운 라이선스나 재배포 허여를 부여하지 않는다.

원본의 픽셀과 alpha는 수정하지 않는다. 사용자가 원본 보존 및 표시용 복사본 정리를 직접 위임한 범위에서, 각 프레임의 실제 전신 crop 바깥 alpha만 0으로 정리한다. 전체 RGB·crop 내부 RGBA·해상도·색프로필을 보존하고 검사한다. 이미지를 리샘플하지 않고 표시 좌표로 크기와 발 위치를 맞춘다. 원장의 직군별 `eyeLineRatio`는 실제 전신 bbox에 대한 눈 중심의 수동 보정값이며 안경·선글라스에만 적용한다. 다른 꾸미기 요소와 몸체 좌표에는 누적하지 않는다. 기존 colorist 몸높이 189와 발 기준 188을 보존하기 위해 target의 상단 좌표만 -8까지 허용하며, source·다른 경계·투명 gutter 검사는 유지한다. PD 최초 전신 후보는 행 경계 침범으로 채택하지 않고 내장 생성기로 배치를 수정했으며, 첫 원본도 private QA에 보존했다.

앞선 얼굴 부분 합성 시도는 확대 화면에서 머리·눈 경계가 어색해 채택하지 않았다. 해당 원본 8개와 수정 시도, 통과·실패 검증 기록은 private QA에 보존했다. 앞선 부분 합성 입력의 53개/69개 테스트와 전체 타입 통과를 새 전신 입력의 통과로 계산하지 않는다.
