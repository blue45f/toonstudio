# 새 프로젝트 키보드 시작·모바일 입력 복구 — 2026-10-31

상태: **구현·검토용 PR / 앱 통합 실행 검증 대기**. PR #2607의 필수 선택 우선 동선을 이어서 보완한다. 운영 반영이나 서비스 전체 100점 달성을 뜻하지 않는다.

## 사용자 경험

프로젝트 이름을 입력하고 Enter로 시작할 수 있다. Enter와 버튼 클릭은 동일한 제출 경계를 사용하며, 이름·크기가 잘못되면 해당 입력란으로 초점을 옮긴다. 크기 설정이 접혀 있으면 기존 복구 동작으로 먼저 펼친다. 생성 버튼은 여전히 하나다.

한글 등 IME 조합 중 Enter, 조합 종료 경계 keyCode229, 반복 키, 수식키 Enter는 새 프로젝트를 생성하지 않는다. 선택상자·접기·여러줄 입력·보조 버튼의 기본 조작은 가로채지 않는다. 동기 submit 재진입과 연속 요청을 막으며, 실제 생성 콜백이 실패를 반환하거나 예외를 던지면 재시도 잠금을 해제한다. 입력값을 초기화하지 않는다.

생성 오류는 초점을 받을 수 있는 안내로 연결하고 시작 버튼의 설명에도 연결한다. 생성 진행 중에는 다음 화면 대신 진행 상태를 알린다. 모바일 크기 입력은 너비·구분자·높이를 축소 가능한 grid로 묶고, 초기화 버튼은 별도 행에 둔다. 작은 화면의 입력·선택 글자는 16px로 설정한다.
