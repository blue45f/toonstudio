# BG3D 기본 상자 원본 면 편집

- 상태: `current` — 독립된 단색 기본 상자의 면 편집과 같은 ID의 모델 교체.
- 기준일: 2026-10-29.
- 전체 SketchUp 요구 SK33의 일부다. 원본 mesh를 보관한 파생 모델의 반복 편집은
  [별도 지원 경로](bg3d-authored-model-face-edit.md)이며 일반 모델·부모 계층까지 완료한 상태는 아니다.

## 사용자 경로

1. 정밀 3D 편집에서 기본 상자 하나를 선택한다.
2. `보기 → 배경 건축 · 3D 도구 열기 → 배경 건축 · SketchUp`에서 `선택한 상자 면 편집`을 누른다.
3. 실제 원본의 면을 클릭하고 밀기/당기기 등 면 도구의 미리보기를 확인한다.
4. 도구의 `적용`으로 로컬 면 편집을 확정한다. 이 단계의 Undo/Redo는 임시 면 편집 안에서만 작동한다.
5. `배경 원본에 반영`을 누르면 검증·저장이 끝난 뒤 같은 오브젝트 ID의 편집 모델로 교체한다.
6. 배경 편집기의 실행 취소 한 번으로 원래 상자를 복구하고, 다시 실행하면 편집 모델을 복구한다.

취소하거나 닫으면 배경 원본은 바뀌지 않는다. 적용 대기 중에는 중복 적용·추가 편집·닫기를 막고,
상위 화면이 사라지면 해당 요청의 AbortSignal을 중단한다. 실패하면 로컬 편집 결과를 보존해 재시도한다.
목록 갱신만 실패한 경우 이미 완료한 교체를 되돌리지 않고 별도 안내를 남긴다.

## 현재 지원 경계

- 숨김·잠금이 없는 기본 `box` 하나이며 부모·자식·컴포넌트·연결 복제 관계가 없어야 한다.
- 단색과 기본 재질을 지원한다. 표면 페인트·절차 재질·재질 조정을 임의로 제거해 적용하지 않는다.
- 기존 장면에서 그림자 투사·수신을 끈 노드나, 런타임 변환에서 보존되지 않는 원본 첨부가 있으면
  정보 손실을 막기 위해 적용 전에 명시적으로 거부한다.
- 새 authoring 데이터를 보관한 변환 모델은 이동·회전·크기 조절 후 `선택한 편집 모델 면 편집`으로 다시 연다.
  [반복 편집의 원본·현재 배치·지원 경계](bg3d-authored-model-face-edit.md)를 따르며 기존 데이터 없는 GLB는 지원하지 않는다.
- 원래 위치·회전·비균일 배율을 유지한다. 면 도구의 치수는 도형의 로컬 단위이며 비균일 배율의 월드 거리는 다르다.
- 임시 편집기는 기존 DCC 전역 작업공간이나 복구 저장소를 덮어쓰지 않는다.

## 데이터·명령 경계

원본은 실제 `makeGeometry` 형상에서 안정 ID를 가진 half-edge mesh로 변환한다. 상자는
24개 렌더 정점을 8개 원본 정점과 6개 사각 면으로 대응시키고 원본 삼각형 ID를 별도로 기록한다.
최초 자산 등록보다 이전으로 로컬 Undo할 수 없다. 미리보기나 오브젝트 변환을 조용히 버려 내보내지 않는다.

확정된 mesh를 GLB로 내보내 원본 단색·roughness 1·metalness 0·depth bias와 v1 원본 mesh 데이터를 기록한 뒤,
기존 Worker 검증과 atomic 저장, 실제 렌더 admission을 거친다. 선택·원본 정본 지문·모달 세션·저장 record·
캐시 소유권·현재 품질 정책을 다시 확인하고 정본 교체와 즉시 history를 한 번 발행한다.
렌더 캐시의 2 m 정규화 배율 `k`에는 인스턴스 배율 `원래 배율 / k`로 대응한다.
자산의 저장 ID와 장면 attachment ID를 혼용하지 않는다.

새 cache는 독립 staging map에서 준비한다. 실패·취소 시 해당 호출의 생성 receipt와 소유 자원만 정리한다.
다른 세션·manifest revision·cache 소유자가 채택한 자산이나 부분 commit 가능성이 있는 자산은 삭제하지 않고
남은 자산과 재시도 상태를 안내한다. 이 경로의 실패가 기존 고품질 모드를 자동으로 낮추지 않는다.

단축키 경계는 바깥 배경의 Delete·Undo/Redo를 차단한다. 로컬 Ctrl/Cmd Z·Shift Z·Y는 로컬 history에만 적용한다.
원본 교체·배경 Undo/Redo로 렌더 객체가 바뀌면 장면에서 빠진 변형 기즈모 대상을 즉시 분리한다.

## 검증과 남은 목표

실제 브라우저의 원본 선택·면 클릭·Push/Pull·로컬 Undo/Redo·Worker/OPFS 저장·같은 ID 교체·배경 Undo/Redo·
PNG 캡처·문서 저장·새 마운트 복원을 확인했다. 상세 수치·현재 검증 한계는
[원본 면 편집 검증 기록](../reports/bg3d-primitive-face-edit-2026-10-29.md)에 기록한다.

정확한 원본 mesh 권위를 가진 새 파생 GLB의 재선택·재열기·반복 편집은
[편집 모델의 원본 면 재편집](bg3d-authored-model-face-edit.md)에 지원 범위와 검증 상태를 기록한다.
authoring이 없는 기존 GLB의 Float32 렌더 좌표와 topology provenance만으로 원래 double 좌표를 복원하지 않는다.
일반 도형·계층·페인트·컴포넌트·외부 모델의 직접 편집은 별도의 원본 보존 검증이 필요하다.
