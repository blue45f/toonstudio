# 로그인 이후 사용성·인증 복구 고도화 — 2026-10-30

상태: **current — 작업 브랜치의 구현·검증 범위**. 운영 반영과 서비스 전체 100/100 판정은 별도의 증거가 필요하다.

## 사용자 경험 개선

### 프로필 편집

- 조회가 준비되지 않았거나 실패한 동안 빈 값으로 기존 프로필을 덮어쓸 수 없게 한다. 조회 실패에는 다시 불러오기 버튼을 제공한다.
- 기본 폼은 사진·이름·소개에 집중하고 직무·협업 상세는 선택적으로 펼친다. 계정 탭을 왕복해도 작성 중 입력은 유지한다.
- 실제로 바뀐 필드만 PATCH한다. 소개만 고친 저장이 다른 화면에서 변경한 이름·직무를 되돌리지 않는다.
- 동일 폼의 중복 저장은 즉시 막는다. 실패 시 입력은 보존하고 성공 응답만 반영한다. Enter 제출과 명시적인 레이블·오류·저장 결과를 지원한다.
- 변경 중 새로고침/닫기에는 beforeunload 보호를 적용한다. **임의의 다른 SPA 경로로 나가는 모든 상황을 막았다고 주장하지 않는다.**

### 계정·요청 순서 경계

로그아웃·계정 교체·저장·캐시 무효화가 일어나면 이전 조회 결과가 새 상태를 덮어쓰지 못한다. 동일 계정으로 다시 로그인해도 이전 세대의 응답은 거절한다. 잘못된 필드 타입이나 다른 계정의 서버/탭 응답은 캐시·세션·입력 폼에 넣지 않는다. 브라우저가 BroadcastChannel을 차단해도 기본 조회는 동작한다.

### 인증 무응답과 취소

Google 토큰 로그인·기존 계정 로그인·로그아웃은 응답 헤더뿐 아니라 JSON 본문 읽기와 재시도를 포함해 하나의 75초 상한을 사용한다. 세션 확인은 전체 5초 상한을 사용한다. 타임아웃·취소는 성공이 아니다. 늦은 성공 응답은 취소 뒤 세션을 되살리지 않는다. 로그아웃을 확인하지 못하면 미확정 안내와 같은 메뉴의 다시 시도를 유지하고, 후속 요청은 멈춘 이전 Promise를 재사용하지 않는다.

### 즉시 작업 화면

설정·계정·인증·메시지·알림·제작 관리 등의 직접 작업 경로에서 장식용 진입 연출을 생략한다. 공개 소개 화면의 연출은 그대로 둔다.

### 캐릭터 표정 적용 교착

자연 미소를 고르면 선택 표시만 바뀌고 캔버스 삽입·출력이 잠기는 현상을 실제 브라우저에서 재현했다. 표정 카드 선택은 가중치의 파생 표시인데, 카드에 해당하지 않는 사용자 표정을 중립으로 반복 초기화해 정본 가중치 적용에 도달하지 못했다. 전용 expression 문서만 재생하도록 수정하고, 실패 회귀 및 undo/redo를 추가했다.

3D 브라우저 테스트는 현재 카테고리→세부 부위 탐색과 접힌 출력 설정을 실제로 열도록 갱신했다. 선택 표시뿐 아니라 런타임 적용 후 출력 가능 상태를 확인한다. PSD 테스트는 존재하지 않는 밑색·음영을 만들어내라고 기대하던 fixture를 실제 패스로 보완하고, 밑색이 없으면 헤어 그룹이 생기지 않는 반대 검사도 추가했다. 제품 출력 제한을 느슨하게 바꾸지 않았다.

## 실패를 숨기지 않은 기록

- 인증 무응답·본문 지연·늦은 응답 6개 테스트를 수정 전 실행해 모두 실패함을 확인하고 수정 후 통과했다. 추가 요청 수명/재시도 경계를 포함한 전용 테스트는 11개다. 늦은 401 응답이 타임아웃 이후 세션을 지우지 않는 검사도 추가했다.
- 서버 프로필 필드가 잘못된 5개 사례를 수정 전 실패로 확인하고 입력 검증 추가 후 통과했다.
- 타이머 정리 검사의 초기 두 실패는 jsdom의 storage 이벤트 타이머까지 센 잘못된 검사였다. 인증 요청이 만든 정확한 timer handle을 clearTimeout하는지 검증하도록 바꿨다. 전체 대기 상한·취소 검사를 완화하지 않았다.
- 이전의 빈 DB 검사 실패를 제품 결함으로 집계하지 않았다. 필요한 스키마가 존재하는 격리 복제본에서 통합 검사 218개를 실행했다.

### 브라우저 검증 기록 저장 장애

3D 15개 실행 중 가로 화면 PNG 검사는 이미지 서명·해상도 확인 뒤 브라우저 context/trace를 저장하는 단계에서 `ENOSPC`로 종료됐다. 이전 생성 `dist/`만 정리했고 코드·사용자 원본·실패 증거는 보존했다. 해당 검사의 재실행 결과는 원본과 분리해 기록한다. 15개가 한 실행에서 처음부터 모두 성공했다고 쓰지 않는다.

## 백업 복원 위험 — 미해결

일반 pg_dump/pg_restore에서 검수 음성 메모 트리거가 참조한 `pg_catalog.studio_review_voice_note_guard()`가 누락되어 복원이 실패했다. public와 pg_catalog에 동명 함수가 공존하는 기존 0093 경계다. **운영에서 재현했다고 주장하지 않으며, 운영 DB를 변경하지 않았다.**

[이슈 #2581](https://github.com/blue45f/toonstudio/issues/2581)에 재현·수정 조건을 남겼다. 기능 테스트를 위한 별도 격리 복제본에만 원본과 동일한 시스템 함수 정의를 명시적으로 보존했다. 통합 검사 통과는 일반 백업 복원 결함 해결을 뜻하지 않는다. 기배포 migration 원문을 고치거나 제약을 제거하지 않았다.

## 100점 완료 기준과 남은 범위

상태: **target**. 실제 운영 OAuth, 모든 역할·데이터의 UI 생성/수정/삭제, 기기 간 저장과 실시간 협업, 결제·유료 AI, 정상 GPU 3D 전체 저작, 실물 휴대폰·펜 입력과 실제 초보자 평가가 남아 있다. 자동 테스트 비율은 사용성 점수가 아니다. 이미 알려진 결함이나 미검증 기능을 완료로 표시하지 않는다.

## 재현

저장소 루트와 설치된 의존성이 전제다.

```sh
pnpm exec vitest run apps/web/src/domains/auth apps/web/src/domains/account \
  apps/web/src/platform/me-client.test.ts apps/web/src/platform/me-client.recovery.test.ts \
  apps/web/src/app/entry-intro-policy.test.ts --maxWorkers=2
pnpm harness:verify
node scripts/local-fullstack/cli.mjs e2e
```

마지막 명령은 loopback 검증 하네스가 준비된 상태에서만 실행한다. 비밀값은 무시된 로컬 env에만 있고 로그·문서·커밋에 포함하지 않는다. 운영 도메인과 계정을 입력하지 않는다.
