## 1. 실제 개선

### 저장 안내의 범위를 사실대로 표시

기기 저장 receipt를 서버 저장으로 설명하지 않는다. `이 기기에 저장됨`, `이 기기에 저장 중`, `아직 저장 기록 없음`을 나누고, 서버 저장 확인이 없는 화면에서는 확인할 수 없다고 표시한다. 다른 기기에서 자동으로 이어진다는 근거 없는 문구도 제거했다. 대기열 진행률은 실제 로컬 저장 영역에 배치했다.

### 모바일 편집과 관리자 조작

모바일 편집 안내는 짧은 요약부터 보여 주고 가능한 작업·제한을 펼쳐 볼 수 있다. 닫은 뒤 재진입 버튼을 유지하며 포커스를 복원한다. 하단 도크와 안전 영역을 고려하고, 작업 표면이 바뀌면 그 표면의 제한 안내를 다시 판단한다. 주요 모바일 진입 버튼·링크는 44px 높이와 줄바꿈을 지원한다.

관리자 모바일 탐색과 명령 검색을 기존 Radix Dialog로 구성해 초점 이동, Tab 순환, Escape 닫기, 원래 버튼으로 복귀를 보장했다. 넓은 화면으로 전환하면 숨겨진 모바일 메뉴가 본문을 잠그지 않는다. 메뉴 제목 ID 중복, 모바일 아이콘 검색 버튼의 접근 가능한 이름, 검색 입력의 명시적 이름도 보완했다. 한글 조합 중이거나 이미 소비된 단축키로 검색창을 열지 않는다.

### 화면 가독성

컷 제작 기본 버튼의 흰색 글자가 읽히도록 배경색을 조정했다. 비활성 입력 영역의 설명까지 흐려지던 전체 opacity를 제거했다. 3D 간편·프로 모드의 선택 글자는 배경 대비가 더 높은 기존 전경 토큰을 사용한다.

### 긴 페이지 증거 기록

촬영 전후에 문서가 줄어들면 해당 시도를 최종 완료 목록에서 제외하고 맨 위부터 다시 기록한다. 최대 3회 재시작 이후에는 명확하게 실패한다. 스크롤이 진행되지 않는 경우 동일 화면을 반복 저장하지 않는다. 촬영 실패·가로 넘침은 숨기지 않으며 원래 스크롤과 실제 viewport를 유지한다. 늘어나는 무한 피드는 시작 시 경계까지만 유한하게 기록한다.

### 전수 점검의 누락·과대 판정 방지

실제 경로 선언과 import/spread, Studio 별칭, 학습 콘텐츠 ID를 따라 경로 목록을 수집하고 출처를 남긴다. 준비 중·빈 화면·오류·권한 안내를 정상 기능 완료로 세지 않는다. 특히 주소가 `/admin/overview` 그대로여도 로그인/권한 안내만 나오면 `auth-gate`로 분류한다. 긴 실행이 중단되어도 각 관측 JSON은 즉시 보존한다.

## 3. 발견한 실패를 어떻게 다뤘는가

- 이전 공개 체험 테스트는 접혀 있는 `details`를 열지 않은 채 내부 버튼을 검사했다. 실제 키보드 Enter로 여는 과정을 추가했다. 데모를 강제로 항상 열거나 화면을 숨겨 통과시키지 않았다.
- 버튼 검사에서 그라데이션의 `background-color: transparent`를 읽기 불가능으로 오인했다. 단색·선형 그라데이션의 실제 색, 투명 조상의 합성 배경, 최소 명도 대비 4.5를 검사하도록 보강했다. 검사기 자체가 저대비를 거부하는 테스트도 추가했다. 이 제한된 검사는 전체 WCAG 인증이 아니다.
- 관리자 인증 fixture의 `image` 필드 누락을 서버 세션 파서가 정상적으로 거부했다. fixture를 계약에 맞게 고쳤고 인증 코드는 느슨하게 바꾸지 않았다.
- 모바일 안내 단위 테스트의 잘못된 `exact` 옵션 7개를 올바른 Testing Library 호출로 고친 뒤 전체 타입 검사와 11개 회귀를 다시 통과했다.
- Vitest 전용 DB 테스트를 Node test runner로 호출한 초기 실행은 실패했다. 올바른 Vitest 실행에서 33개를 검증했다. 도구 실행 오류를 제품 결함으로 집계하지 않는다.

## 6. 재현 명령

저장소 루트, 의존성과 Playwright Chromium 설치 상태가 전제다.

```sh
pnpm harness:verify
pnpm exec playwright test --config playwright.non-studio.config.ts \
  capture-page-evidence.spec.ts readable-controls.spec.ts \
  admin-navigation-accessibility.spec.ts atelier-public-polish.spec.ts \
  non-studio-controls.spec.ts --workers=1
pnpm exec playwright test --config playwright.non-studio.config.ts \
  non-studio-experience.spec.ts --workers=2
```

`playwright.non-studio.config.ts`는 기존 `dist/`의 Vite preview를 사용한다. UI 수정 후에는 새 최적화 번들을 먼저 만들어야 한다. 이번 실제 실행은 같은 설정에 로컬 preview `127.0.0.1:5319`를 지정한 산출물 디렉터리의 임시 설정을 사용했다.

실제 로그인 검증은 `scripts/local-fullstack/README.md`의 loopback 가드를 통과한 별도 스택에서만 실행한다. 운영 주소·계정을 넣지 않는다. `up`은 격리 DB를 만들고 시드하며, `down`은 해당 스택만 종료하고 데이터를 보존한다.
