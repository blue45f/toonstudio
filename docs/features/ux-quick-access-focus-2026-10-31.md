## 사용자에게 보이는 변경

- 모바일 팔레트 닫기를 X 아이콘뿐 아니라 `닫기` 텍스트로 표시한다. 44px 높이와 기존 작업으로의 초점 복귀를 유지한다.
- 화면 읽기 도구가 pointerdown 없이 click을 전달해도 배경 닫기가 동작한다. 일반 포인터 click은 이미 처리한 pointerdown과 중복 실행하지 않는다.
- Tab/Shift+Tab이 링크·여러줄 입력·접기 제목을 빠뜨리지 않게 한다. 음수 tabindex, 비활성 fieldset, 숨김·inert 항목은 건너뛰며 양수 tabindex와 라디오 그룹의 실제 이동 순서를 고려한다.
- 모달 자체에 초점이 있을 때도 내부 첫/마지막 항목으로 이동하며, 중간 이동은 브라우저 기본 동작을 유지한다. 별도로 열린 모달의 Tab을 가로채지 않는다.
- 한글 조합 취소 Escape, IME229 경계, 하위 편집기가 이미 처리한 Shift+Q는 팔레트를 닫지 않는다. 일반 Escape·Shift+Q와 데스크톱 비모달 동작은 유지한다.
