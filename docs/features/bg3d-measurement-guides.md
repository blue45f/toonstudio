# 공간 모델러 측정 가이드의 장면 저장

- 상태: `migration` — `codex/spatial-measurement-persistence-20261102`의 구현 중 증분. main 반영과 실행 검증은 별도다.
- 요구 원장: [SK14 측정·가이드와 SK32 저장·복원](sketchup-feature-coverage.md).
- 제품 이름: 공간 모델러(`Spatial Modeler`). 원본 제품명은 공개 계약과 형식 비교에만 사용한다.

## 현재 증분의 계약

뷰포트에서 두 점을 측정한 뒤 고정한 가이드는 장면 v3의 선택 필드 `measurements`에 보관한다.
가이드의 정본은 ID, 미터 단위의 두 월드 좌표, 길이 잠금, 표시 여부다. `mm`·`cm`·`m` 선택은
표시 단위이며 정본 좌표를 반올림한 문자열로 바꾸지 않는다.

저장 소비자와 측정 도구는 기존 `@toonstudio/studio-project-model`의 렌더러 중립 측정 문서 코덱을 함께 사용한다. 추론·포인터·렌더링 도구는 초기 장면 읽기 경로로 가져오지 않는다.

필드가 없는 기존 장면에는 빈 측정 문서를 자동으로 쓰지 않는다. 읽기 화면에서만 동일한 cm
기본값을 사용하므로 기존 v3 직렬화 바이트와 저장된 원본 해시를 보존한다. 명시된 측정 필드가
손상됐으면 필드를 버리고 장면을 여는 대신 거부한다. 가이드 최대 256개·측정 문서 64 KiB와
장면 전체 320 KiB의 기존 상한을 모두 적용하며, 일부 가이드만 잘라 저장하지 않는다.

가이드 추가·삭제·표시·단위 변경은 최신 정본 장면을 검증한 뒤 즉시 이력 하나와 정본 변경
하나로 반영한다. 같은 값은 이력을 추가하지 않는다. 화면이 가진 이전 측정 문서와 현재 문서가
다르거나 장면 복원·캡처·물리 재생이 진행 중이면 변경을 거부한다. 패널은 장면 명령의 수락을
확인한 뒤에만 성공 안내를 표시한다.

측정 시작점, 마우스를 따라 움직이는 임시 끝점, 추론 미리보기, 현재 도구의 길이 잠금 입력은
작업 중 상태다. 고정한 가이드와 구분해 저장하지 않는다. 가이드 렌더 객체는 기존 캡처 제외
계약을 유지하므로 최종 웹툰 배경 이미지에 보조선이 구워지지 않는다.

## 템플릿 저장과 적용

가이드가 있는 장면은 일반 도형이 없어도 템플릿 저장 대상이다. 템플릿 적용은 도형과 가이드를
같은 검증·이력 경계에서 처리해야 한다. 기존 장면 가이드를 보존하고 유입 가이드의 ID가
충돌할 때만 새 ID를 할당한다. 월드 좌표와 길이 잠금·가시성은 유지한다. 기존 가이드가 있으면
현재 표시 단위를 유지하고, 없으면 템플릿 단위를 적용한다.

가이드 수·중첩 문서·전체 장면의 한도를 넘으면 도형, 가이드, 이력, attachment 연결을 일부만
변경하지 않는다. 측정 필드가 없는 이전 템플릿은 현재 장면의 측정값과 표시 단위를 바꾸지 않는다.

## 검증 상태와 남은 전체 요구

이 증분은 소스와 회귀 테스트 작성 단계다. 집중 단위·통합 테스트, 전체 하네스·타입 검사,
정상 커밋 후크, 실제 브라우저의 저장·재열기는 아직 통과 증거가 없다. 메모리·디스크 상태와
다른 3D 검증의 실행 순서를 맞춘 뒤 수행하고 정확한 입력과 결과를 기록한다.

공식 [ConstructionLine 계약](https://ruby.sketchup.com/Sketchup/ConstructionLine.html)은 유한·반무한·무한선과
독립적인 시작·끝점, 위치·방향을 구분한다. [Length 계약](https://ruby.sketchup.com/Length.html)은 원본 내부
길이 단위와 반올림된 표시 문자열을 구분한다. 이는 공개 동작 계약이며 네이티브 알고리즘을
이번 증분에서 실행·분석했다는 뜻은 아니다.

이번 월드 두 점 거리 가이드만으로 무한·반무한 보조선, 보조점, 각도기, 사용자 축,
geometry 참조에 따라 갱신되는 치수, 원본 SKP 보조 엔티티의 편집 정본 복원을 지원한다고
판정하지 않는다. 해당 요구와 기존 parser/restorer의 반무한 끝점 보존 공백은 SK14–15의
후속 요구로 유지한다. 전체 SK01–SK33 기능 목표는 미완료다.
