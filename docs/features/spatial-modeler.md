# 공간 모델러(Spatial Modeler)

- 상태: `current` — 2026-10-29 로컬 구현 및 후속 검증. 운영 배포 상태를 뜻하지 않는다.
- 범위: ToonStudio 자체 건축 생성기, 선택 도형의 선형·원형 배열, 실제 BG3D 장면 명령 연결.
- 브라우저·성능 기준: [Chrome 우선·품질 보존·게임엔진 검토](3d-web-performance-policy.md).
- REA 조사: [2026-10-28 재검증](../reports/sketchup-rea-integration-2026-10-28.md).
- 전체 목표의 진행·미완료 항목: [SketchUp 기능·검증 원장](sketchup-feature-coverage.md).

## 사용할 수 있는 기능

3D 배경 편집기의 **보기 → 공간 모델러 열기 → 공간 모델러**에서 건축 요소를 만든다.
직선·L자·나선 계단, 박공·모임·한옥 지붕, 돌출 베이 윈도우, 아치형 정문, 열주 회랑의
9종 기본 도형 조합을 제공한다. 원본 SketchUp의 정확한 형상이나 전체 CAD 기능과 동등함을 뜻하지 않는다.

가로·높이·깊이를 미터로 입력하고 계단 단수 또는 열주 경간 수, 배치 X/Y/Z를 정한다.
입력은 생성기가 지원하는 범위에서 검증하며, 빈 값이나 범위를 벗어난 값을 임의로 보정해 넣지 않는다.
치수는 기본 부품과 배치 간격의 기준이다. 처마·회전 계단 등을 포함한 전체 외곽 크기는 입력값과 다를 수 있다.
나선 계단에서는 사용하지 않는 깊이 입력을 비활성화하며, 분할 수는 계단·회랑에서만 사용한다.
배치한 도형은 기존 3D 편집기의 장면 구성 요소가 되므로 선택·이동 등 기존 편집 경로를 사용한다.

생성 결과는 `EditorSidebarExtras → ViewPanel → SpatialStoryboardLauncher → AdvancedWorkbenchHub`의
명시적인 삽입 포트를 지나 기존 `addGeneratedParts` 명령으로 전달된다. 별도의 예제 배열을
장면 저장의 정본으로 삼지 않는다. 삽입마다 ID를 재발급하며 배치 내부의 부모·연결 참조를 함께 재매핑한다.
편집 잠금·장면 노드 한도 등으로 거부되면 배치 수를 올리거나 성공 안내를 표시하지 않는다.

## 선택 도형의 반복 배치

건축 요소를 배치하면 생성한 묶음 전체가 선택된다. **선택 도형 반복 배치**에서 현재 선택한 기본 도형을
장면 기준 X/Y/Z축으로 선형 복제하거나, 입력한 중심·축을 기준으로 원형 복제한다.
원본을 제외한 사본만 추가하며, 복제 결과 전체를 다시 선택한다.

| 명령 | 동작 | 예시 |
| --- | --- | --- |
| `*N`, `Nx` | 입력 간격마다 N개 사본 생성 | `*3`, X축 2m → 원본에서 2m·4m·6m 위치 |
| `/N` | 전체 거리·각도를 N등분하고 끝점까지 N개 사본 생성 | `/4`, 전체 8m → 2m·4m·6m·8m 위치 |
| 원형 `*7`, 45도 | 원본을 포함한 8개를 한 바퀴에 배치 | Y축과 중심 X/Y/Z를 함께 지정 |

부모의 회전·크기를 반영한 월드 변환을 사용한다. 부모와 자식을 함께 복제하면 새 부모 아래의 local 변환을
유지한다. 선택 밖 부모에 속한 도형은 월드 변환을 보존한 독립 사본으로 만들며, 기울어짐을 TRS로 보존할 수
없으면 실행을 거부한다. 기존 외부 모델이 함께 선택됐거나 선택·부모 계층에 숨김·잠금·손상된 참조가 있어도
일부 도형만 복제하지 않는다.

선택 수·추가할 도형 수·현재 노드 여유를 표시한다. 실행 시 최신 상태를 다시 검사하고, 최종 ID와 기존 모델을
포함한 전체 문서가 저장 가능한지도 확인한다. 위치 ±10,000m, 양수 scale 0.001~1,000과 문서 용량 한도에서
변환을 보존할 수 있어야 한다. 원형 배열의 360도 끝점처럼 원본·다른 사본과 같은 회전은 중복 생성하지 않는다.
성공한 건축 배치와 배열은 각각 즉시 Undo 경계를 기록하므로 연속 실행도 한 명령씩 되돌릴 수 있다.

## 예제와 현재 지원의 구분

작업대 아래 **모델링 예제 · 계산 미리보기**의 SKP 복원, Push/Pull·Follow Me·배열,
치수·보조선, 태양광, CAD 내보내기는 내장 샘플로 계산한다. 현재 선택한 모델을 수정하거나
실제 사용자 장면을 내보내는 기능으로 해석하면 안 된다. 지형 편집·솔리드 예제는 명시적인
배치 버튼으로 실제 장면에 추가할 수 있다. 기존 SKP 가져오기와 기본 면 편집 기능의 지원 범위는
각 기능의 소스·테스트를 따른다.

현재 UI는 `StudioBg3dSpatialModelerPanel.tsx`와 예제 영역의 `StudioBg3dSpatialModelerSections.tsx`로
구성하며, 고급 작업대의 탭 식별자는 `spatial-modeler`다. 원본 면 편집과 현재 장면 출력 범위는
[기본 상자 면 편집](bg3d-primitive-face-edit.md), [편집 모델 재편집](bg3d-authored-model-face-edit.md),
[현재 장면 GLB 출력](bg3d-current-scene-glb-export.md)을 각각 따른다.

## 남은 검증과 목표

2026-10-28 초기 조사에서는 SketchUp 원본 CAD 커널, 로그인 뒤 WebAssembly, 데스크톱 내부 알고리즘을 분석하지 않았다.
2026-10-29에는 공식 native writer의 제한된 경로를 Ghidra로 정적 분석했으며, 범위와 제약은
[native 조사](../reports/sketchup-native-rea-2026-10-29.md)와 [장면 출력 조사](../reports/sketchup-scene-export-rea-2026-10-29.md)에 구분한다.
전체 CAD 커널과 로그인 뒤 WebAssembly는 여전히 미확인이다.
선택 면·정점을 직접 바꾸는 Follow Me, 실제 장면의 CAD 내보내기, SketchUp과의 완전한 왕복 호환은
이 변경의 완료 범위가 아니다. 2026-10-29 실제 BG3D 편집기의 WebGL2 렌더·캡처·localStorage 문서 저장·새 인스턴스 재개방을 검증했다.
위 화면 검증은 제품 이름 변경 전의 증거다. 명칭·모바일·품질 보존 변경 뒤
[14파일 113회귀·scoped 타입·정적 검사](../reports/spatial-modeler-quality-validation-2026-10-29.md)는 통과했으며 새 브라우저 검증은 대기 중이다.
전체 Studio 캔버스의 저장 repository와 운영 환경 스모크는 별도 검증이 필요하다.
