# ToonStudio 전수 UI/UX 고도화 시안 및 통합 개편 설계서 (v2 Blueprint)

- 문서 상태: **current + migration** (기준일: `2026-11-11` — **16개 전수 화면군 `시안 A ~ 시안 P` 100% 핵심 UI/UX 컴포넌트·브리지·단위 테스트 `current` 코드 반영 완료**, 기존 북마크·외부 공유 URL 호환을 위한 레거시 별칭 경로는 `legacy exception`으로 100% 무손실 보존)
- 상위 정본: 제품 범위와 원칙은 [PRODUCT.md](../../PRODUCT.md), 시각·토큰·레이아웃 계약은 [DESIGN.md](../../DESIGN.md), 아키텍처 경계는 [ARCHITECTURE.md](../../ARCHITECTURE.md)를 따른다.

## 1. 개편 배경 및 모노레포 전수 감사 요약

모노레포 산하 **7개 애플리케이션(`web`, `api`, `admin-web`, `brush-lab`, `character-lab`, `mobile`, `desktop-sync`), 웹 라우트 24개 그룹(총 376개 경로·패턴·별칭), 스튜디오 문서 작업공간 13종, 에디터 메인 메뉴 18개 그룹, 3D 하이브리드 DCC 6대 전문 모드, 운영자 콘솔 16개 탭, 데스크톱 루프백 동기화 충돌 콘솔**을 전수 대조 감사한 결과 다음 4가지 핵심 사용성 병목을 도출하고 Wave 1 ~ Wave 6에 걸쳐 코드로 해결했다.

1. **진입 관문 중복(7개 홈·시작 화면 충돌) 및 초기 세션 대기 병목**: `/`(사이트 홈), `/home`(개인 작업 홈), `/hub`(둘러보기), `/create`(시작 시트), `/studio`(크리에이터 로비·내 작업), `/studio/new`(생성 폼), `/studio/p/:projectId/overview`(프로젝트 홈) 간 동선을 정렬하고, 백엔드 콜드스타트 시에도 3초 내(`INITIAL_SESSION_READY_DEADLINE_MS = 3_000`) 게스트·로컬 화면이 즉시 열리도록 비차단 세션을 적용했다.
2. **에디터 상단 크롬 과밀 및 공정 전환 탐색 비용**: 에디터 상단에 `콘티·3D·작화·식자·검수` 5단계 제작 공정 1클릭 피일 바를 결합하고, `고급 도구 펼치기 (도구 막대)`(`studioUiAdvancedToolsToggleAccessibleName`, WCAG 2.5.3 준수)로 초보자 집중 모드와 전문가 도구를 분리했다.
3. **페이지 단절형 제작·리서치·보조 도구 배치**: 3D 배경(`/studio/bg3d`)에 접이식 3D 에셋 쉘프 및 6대 DCC 전문 모드 전환 바를 통합하고, 에셋 허브(`/studio/assets`)에 브러시 V6·오디오·모션·Luna AI·엔진 큐 스위트를, 공개 데이터 창작실(`/research/open-data` 14개 기관)에 창작 목적별 즉시 필터를 배치했다.
4. **출고·마켓·커뮤니티·내 공간·리더·어드민·데스크톱 동기화 연결성**: 출고 프리플라이트(슬라이스 + Rights BOM), 마켓 상세 Rights BOM 배지, 개인 프로젝트↔팀 프로덕션 5열 공정 칸반 브리지, 쇼케이스 4탭 소셜·캐릭터챗 허브 바, 내 공간 API 키 볼트·복구 금고·쉬어가기 바, 회차 리더 2.5D 공간 리더·3컷 창작 브리지, 연재 센터↔스튜디오 출고·기술 아틀라스 교차 브리지, Admin 도메인 그룹 아코디언, `desktop-sync` Starlight OKLCH 44px 충돌 해결 콘솔까지 전수 반영했다.
