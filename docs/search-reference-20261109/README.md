# 검색 시안 후속 검증 · 2026-11-09

상태: current. 검색 화면 보조 검색 동선을 구현했고 필수 전체 검증·원격 통합은 진행 중이다.

## 범위와 시각 대조

- 기준 main: `22341759ed1f645cbb52ff9f3e8dff0f07599b55`.
- 사용자 제공 `search-responsive-concept.png`의 실제 픽셀과 변경 전 실제 앱 캡처를 대조했다. 기존 검색은 필터가 길게 펼쳐져 다른 유형 검색이 약 2,000px 아래에 놓이고, 일치한 유형만 큰 목록으로 노출됐다.
- 검색 전용 컴포넌트에 강좌·매뉴얼·페이지·소재 4개 이동을 추가했다. 390px부터 한 줄, 320px에서는 2열로 배치해 44px 터치 영역을 유지한다.
- 기존 통합 검색 결과·조회 로직은 삭제하지 않고 native details에 보존한다. 반복 열기·닫기는 작품 입력이나 탐색기를 재마운트하지 않는다. 검색어가 없어도 전용 검색 목적지는 유지한다.
- 강좌·소재는 기존 `q` URL 계약을, 페이지는 실제 사이트 디렉터리의 `menu` 계약을 사용한다. 도움말은 검색어 URL을 받지 않으므로 기존 `/help` 계약을 유지한다.
- 긴 데스크톱 필터는 화면 높이 안에서 스크롤한다. 필터 항목과 상태·초점 동작은 그대로 유지한다.
- 이 변경은 검색 화면의 보조 동선 개선이다. 검색창의 전체 너비 재배치, 필터별 접기, 시안 표지 이미지 대체 및 모든 화면의 픽셀 일치를 완료했다고 주장하지 않는다.

## 검증

- Vitest: 검색 배치·경로 전환·fragment·입력/필터 생명주기 4파일 17개 통과.
- 변경 TS/TSX ESLint 및 `git diff --check` 통과.
- 실제 Chrome, 합성 API 응답: 320·390·834·1440px × 스타라이트·밝음·고대비 12조합. 가로 넘침 0, 신규 링크 44px 이상, 페이지 오류 0.
- native details 반복 클릭·Enter, 모바일 필터 Escape와 트리거 초점 복귀, 데스크톱 필터 내부 스크롤을 확인했다. 화면별 결과는 `results.json`, 캡처는 이 디렉터리에 있다.
- `pnpm harness:verify`: lint·Secretlint·아키텍처 게이트 통과, 전체 웹 타입검사 진행 중. 최종 상태는 후속 기록에 남긴다.
- 운영 배포, Gemini 조작, DB 및 기존 작업트리 변경은 수행하지 않았다.

## 재현

저장소 루트에서 전용 로컬 Vite 서버를 127.0.0.1:5297에 실행한다. 실제 운영 API는 사용하지 않는다.

```sh
pnpm exec vite --config apps/web/vite.config.ts --host 127.0.0.1 --port 5297 --strictPort
PLAYWRIGHT_MODULE=/설치된/playwright node docs/search-reference-20261109/qa.cjs
```

`QA_BASE_URL`로 로컬 주소를 바꿀 수 있다. 하네스는 해당 로컬 origin 외 요청을 차단하고 API 응답을 합성 자료로 대체한다.
