## 1. 상황별 복붙용 핵심 메시지 (Copy-Ready Pitch Blocks)

### 1.1 투자자 IR 피치덱용 (30초 엘리베이터 피치)
> 웹툰 1화를 완성하려면 작가는 2D 드로잉, 3D 배경, 식자, 협업·검수, 숏폼 홍보까지 **4~6개 도구를 매주 왕복**해야 합니다.
> **ToonStudio**(`https://www.toonstudio.cloud`)는 이 단절된 공정을 **설치 0초의 브라우저 제작 OS** 하나로 묶었습니다.
> 단순한 웹 캔버스가 아닙니다. 100% 클린룸 7밴드 분광 WebGPU 안료 엔진, Rust WASM 자연매체, 로컬 1 GiB 3D 임포트, 타원 말풍선 2D DP 식자, 출고 전 6대 자산 저작권을 차단하는 Fail-Closed Rights BOM, 캔버스 직결 분업 OS까지 브라우저 안에서 끝납니다.
> 무엇보다 **OPFS SQLite 로컬 권위 저장 + 사용자 기기 WebGPU/WASM/WebAudio/Remotion 로컬 연산 + 서울 onpod·Cloudflare 엣지 하이브리드**로 베타 운영 인프라 고정비를 **월 ₩0**으로 설계했습니다. 트래픽이 늘어도 서버 GPU·렌더팜 변동비가 폭증하지 않는 구조적 단위경제가 핵심 해자입니다.

### 1.2 IT 개발자 · 테크 미디어 홍보용
> 브라우저 탭 하나에서 **7밴드 분광 Kubelka-Munk WGSL Compute 셰이더**, **바이트-결정론 Rust WASM 자연매체**, **Chrome WebHID 왼손 다이얼(TourBox·Wacom EKR·Xencelabs) 바이너리 직결**, **COOP/COEP + Speculation Rules `document.prerendering` 잠금 가드**, **편집기와 1픽셀도 안 틀어지는 포터블 Remotion Render Kit**을 한 번에 돌립니다.
> 저장소 품질 역시 **14,672개 소스 800줄 래칫 · `// @ts-nocheck` 0건 · `creator` 75파일 엄격 린트 경고 0건 · DB 마이그레이션 133/133 드리프트 0건 · 590개 의존성 상용 라이선스 자동 감사**로 통제합니다.

### 1.3 웹툰 작가 · 스튜디오 온보딩 홍보용
> 프로그램 설치도, 기기 인증 옮기기도, 베타 기간 구독료도 없습니다. 링크를 열면 **3초 안에 작업실**이 열리고, 인터넷이 끊겨도 내 브라우저 OPFS에 작업이 안전하게 저장됩니다.
> 기존에 쓰던 **PSD, ABR 브러시, Blender GLB(최대 1 GiB), ACON3D `.skp`(최대 256 MiB)**을 그대로 불러와 컷을 완성하고, 말풍선 자동 조판과 **네이버·카카오·레진·글로벌 안전 슬라이스 + 저작권(Rights BOM) 자동 검사**를 한 번에 통과한 뒤, 10~60초 홍보 쇼츠(Remotion 키트)까지 같은 작품에서 바로 뽑을 수 있습니다.

### 1.4 플랫폼 · 교육기관 · 하드웨어 파트너 제휴 제안용
> ToonStudio는 **웹툰 제작사·아카데미·플랫폼·주변기기 제조사**와 바로 붙는 개방형 웹 제작 OS입니다.
> - **교육기관·대학**: 실습실 PC마다 유료 소프트웨어를 설치·인증할 필요 없이 브라우저 URL 하나로 2D·3D·식자·협업·숏폼 실습 환경 즉시 배포
> - **웹툰 플랫폼·제작사**: 출고 전 Fail-Closed Rights BOM으로 비상업 폰트·3D 소재 법무 사고를 원천 차단하고, 플랫폼 규격(690/720/800px) 말풍선 보호 슬라이스 및 비가시 포렌식 워터마크 외주 보안 제공
> - **하드웨어 제조사(타블렛·왼손 컨트롤러)**: Chrome WebHID 바이너리 직결 및 `ws://127.0.0.1:47615` 로컬 명령 브리지 프로필로 드라이버 설치 마찰 없는 웹 크리에이터 생태계 확장

## 6. 투자자 · 제휴사 핵심 예상 Q&A 6선

1. **Q. 이미 Clip Studio Paint와 Procreate가 시장을 장악했는데, 작가가 갈아탈 이유가 있나요?**
   - **A.** 기존 도구를 하루아침에 버리라고 강요하지 않습니다. PSD·ABR·GLB(1 GiB)·`.skp`(256 MiB) 왕복 호환으로 **공존**하면서, 기존 도구가 해결하지 못한 구간—설치 없는 3초 진입, 3D 배경 컷 합성 왕복 제거, 타원 말풍선 자동 조판, 출고 전 Rights BOM 저작권 차단, 2~6인 어시스턴트 분업 OS, 10~60초 홍보 쇼츠—부터 작업 시간을 줄여 점진적으로 주력 OS로 전환하는 전략입니다([경쟁사 벤치마크 보고서](../benchmarks/toonstudio-global-competitor-device-benchmark-2026-11.md)).
2. **Q. 브라우저 기반이면 성능이나 오프라인 안정성이 떨어지지 않나요?**
   - **A.** 핵심 연산을 JavaScript 메인 스레드에 몰지 않았습니다. 분광 안료는 **WebGPU WGSL Compute**로, 자연매체는 **Rust WASM Dedicated Worker**로, 저장은 **OPFS SQLite + WAL 스크러버 + 멱등 동기화 큐**로 분리했습니다. 인터넷이 끊겨도 로컬에 0ms로 저장되고 재접속 시 충돌을 안전하게 병합합니다.
3. **Q. 베타를 무료로 열면 AI·스토리지·영상 렌더링 서버 비용을 감당할 수 있나요?**
   - **A.** 브러시 GPU, 자연매체 WASM, 효과음 WebAudio, 3D 파싱, Remotion 키트 렌더링, 1차 원고 저장이 전부 **사용자 기기 로컬**에서 돕니다. 덕분에 베타 운영 고정비가 **월 ₩0**(서울 onpod + Cloudflare 무료 티어, 도메인 갱신비 별도)이며, 트래픽이 크게 늘어난 유료 전환 시점에만 `always-on` API와 스토리지를 수익에 맞춰 단계 증설합니다.
4. **Q. 오픈소스나 상용 라이선스(특히 `mixbox`나 Remotion) 때문에 나중에 발목 잡히지 않나요?**
   - **A.** 비상업 `mixbox`(CC BY-NC)는 `2026-11-05` 완전 제거했고 재유입 시 빌드가 깨지는 자동 게이트(`pnpm run audit:licenses`, 590개 의존성)를 걸었습니다. 분광 안료는 100% 클린룸 7밴드 KM으로 자체 구현했고, 물리 엔진 Rapier는 Apache-2.0입니다. Remotion은 현재 1~3인 무료 상용 적격 범위이며, 4인 이상 성장 시점의 라이선스 계약·대체 전환 트리거를 감사 리포트에 미리 문서화해 두었습니다.
5. **Q. 소수 인원으로 이 방대한 코드베이스 품질을 어떻게 유지하나요?**
   - **A.** `AGENTS.md` 단일 계약과 Git Worktree 병렬 스웜, 그리고 5대 자동 래칫 게이트(`eslint --max-warnings=0`, 800줄 파일 크기 상한, `// @ts-nocheck` 0건, Studio 진입 그래프 금지 도메인 감축, 1,206개 문서 링크 자동 검증)로 코드가 커져도 기술 부채가 되돌아가지 못하게 시스템으로 잠갔습니다.
6. **Q. 지금 당장 투자자·파트너가 직접 확인해 볼 수 있는 실물은 무엇인가요?**
   - **A.** 공개 운영 URL `https://www.toonstudio.cloud`에서 결제나 설치 없이 스튜디오 캔버스, 9분 18초 Remotion 제품 투어(`/product-tour`), 경쟁 도구 7종 코드 근거 비교(`/about/compare`), 24씬 IR 발표 플레이어(`/ir/present`)를 즉시 검증할 수 있습니다.
