# 학습 커리큘럼 확장 로드맵 (2026-10-22 확정, 최종 목표 달성 2026-10-22)

상태: current — 최종 목표(레슨 36·용어 90·클래스 8·경로 12)를 달성했다. 기준 수치의 단일 출처는 코드다 — 레슨·용어는
`apps/web/src/domains/learn/learning-content.ts`, 학습 경로는 `learning-paths.ts`,
클래스는 `learning-classes.ts`. 수량은 코드와 계약 테스트(`learning-model.test.ts` 등)가 고정한다.

## 원칙

- 외부 강의 구매·복제 금지. 모든 레슨은 자체 작성 원본만 추가한다.
- 레슨 1개는 기존과 같은 구성(섹션 3개·실습 과제·체크 3개·흔한 실수·퀴즈)을
  갖출 때만 편입한다. 구성 없는 요약 글은 양으로 세지 않는다.
- 제작 워크플로 실습형(스튜디오 트랙)을 우선한다. 개념 강좌만 늘리지 않는다.
- 새 레슨은 학습 경로와 클래스 커리큘럼에 실제로 연결될 때만 완료로 본다
  (경로 합집합 = 전체 레슨을 계약 테스트가 강제한다).
- 콘텐츠는 실제 제품 기능에 근거한다. 연재 캘린더·예약 발행·단계별 마감 계획·
  공지/휴재·독자 분석·역할/권한·동시 드로잉·비교 검수·교실 템플릿·AI 자동 채색·
  3D 배경·마네킹은 모두 레포에 실재하는 기능만 다룬다.

## 완료 기록

1. U5 연재 운영 레슨 4개(일정 설계, 연재 캘린더 실습, 휴재·공지 운영, 독자 지표
   읽기)와 용어 8개, 클래스 1개, 경로 1개를 추가했다. 연재 캘린더·예약 발행·
   단계별 마감 계획·작가 공지·독자 분석 기능의 실배선과 짝을 맞췄다.
2. U6 협업 제작 레슨 4개(역할/권한, 동시 드로잉 실습, 검수·승인, 외주 합의)와
   용어 8개, 클래스 1개, 경로 1개를 추가했다.
3. U7 교육기관 과정 레슨 4개(교실 운영, 과제 설계, 교실 템플릿 실습, 평가
   루브릭)와 용어 8개, 경로 1개를 추가했다. 클래스는 당초 기관용 2개로 나눌
   계획이었으나, 교실 운영 클래스 한 개에 운영·과제·템플릿·루브릭 4주를 통합하고
   나머지 한 자리는 심화 제작 클래스에 배정해 최종 8개를 채웠다.
4. 심화(U8) 레슨 6개(시즌 아크, 컬러 스크립트, 3D 배경·마네킹·AI 자동 채색·
   비교 검수 실습)와 용어 12개, 경로 1개를 추가해 최종 목표를 채웠다.
5. 각 단계마다 레슨 메타(`LESSON_META`)·경로·클래스 연결과 계약 테스트 수량을
   같은 변경에서 갱신했고, 경로 틴트(`learning-path-tints.ts`)도 전 경로분으로
   채웠다.
