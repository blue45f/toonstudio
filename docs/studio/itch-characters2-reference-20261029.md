## 원본 보존과 입력 증명

기존 일반 GLB 정규화기의 상위 경로 거부 규칙은 유지한다. 새 준비 경로는 선정 설정에
명시된 같은 팩의 PNG만 허용한다. GLB 이미지 URI가 가리키는 실제 파일과 승인된 PNG가
같은 파일인지 확인하고 SHA-256·바이트·PNG 헤더 검사와 전체 디코딩을 통과시킨다.
사용하지 않은 승인 파일, 누락·중복 URI, 다른 팩, URL, 심볼릭 링크는 거부한다.

원본 GLB와 PNG는 읽기만 한다. 승인된 이미지를 메모리에서 내장한 GLB가 예상 SHA와
같을 때만 비공개 작업 폴더에 렌더 입력을 만든다. 공개 팩에는 이미지와 매니페스트만
포함하고, 원본 GLB와 atlas를 추가하지 않는다.

새 `renderInputFingerprint` v2는 원본 GLB SHA, 실제 렌더 입력 SHA, 승인 PNG 목록,
정규화기·준비 정책·렌더러의 소스 SHA, 카메라 방향과 리그 정책을 함께 묶는다.
Blender helper가 실제 입력을 검사한 뒤 작성한 proof를 host가 검증하고 동일한 바이트로
보존한다. 과거 렌더 proof를 새 소스 지문으로 덮어쓰지 않는다.
로컬 pack과 proof를 함께 대조한 성공 실행만 증거로 사용한다. 디스크 오류 등으로 중단된
작업 폴더를 완료 증거로 재사용하지 않으며 두 파일의 교체를 단일 파일시스템 연산으로
원자적으로 보장한다고 주장하지 않는다.

리그 표시용 메시 제외는 pose bone의 `custom_shape` 실제 참조로 판정한다. 이름만으로
제외하지 않으며 본체 1개, 리그 1개, 뼈 21개, 가중치 그룹 21개, 해당 리그에 연결된
