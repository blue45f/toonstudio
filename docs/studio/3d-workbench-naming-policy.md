# 3D 작업대 제품 명명 규칙

- 상태: **current — 명명 결정 / migration — 기존 사용자 문구 반영**
- 결정일: **2026-10-30**

## 자체 기능의 표시 이름

- 전체 작업대: **ToonStudio 3D 작업대** / **ToonStudio 3D Workbench**
- 짧은 메뉴 이름: **3D 작업대** / **3D Workbench**
- 세부 기능은 3D 모델링, 조형, UV 편집, 재질 편집, 툰 렌더링처럼 실제 기능을 설명한다.
- 소품은 모양과 용도를 기준으로 이름을 정한다. 제작에 사용한 외부 프로그램 이름을 소품의 제품명 접두어로 쓰지 않는다.
- 외부 제품의 이름이나 로고를 ToonStudio 자체 기능의 제품명·버튼·프리셋 이름으로 사용하지 않는다. 외부 제품과의 동일성, 공식 제휴 또는 전체 기능 구현을 암시하지 않는다.

## 기술 참조와 호환성

- 실제 외부 프로그램용 내보내기·연동 기능은 대상 프로그램과 요구 조건을 정확히 안내한다.
- 라이선스, 저작권, 제삼자 고지와 검증 출처는 원래 이름을 유지한다.
- 저장된 문서의 ID, 자산 경로, 파일 형식, API·코드 식별자와 과거 검증 기록은 표시 이름 변경에 맞춰 임의 변경하지 않는다.
- 이 규칙은 제품 표시 명명 원칙이며 상표 등록이나 법률 검토의 완료를 뜻하지 않는다.
