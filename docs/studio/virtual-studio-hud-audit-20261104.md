# 가상 스튜디오 HUD 겹침·조사·전환 전수 점검 — 2026-11-04

상태: `current`. 이 문서는 2026-11-04 로컬 개발 서버(`127.0.0.1:5190`)에서 확인한 범위와 수정 내용을 기록한다. 운영 배포, 운영 DB, 시크릿, 유료 설정은 건드리지 않았다.
API가 없는 로컬 상태라 서버 협업·실시간 음성은 "연결 중"으로 표시됐고, 콘솔의 502 응답은 이 때문이며 제품 오류로 계산하지 않는다.

## 점검 방법

- 실제 Chrome(CDP)에서 `/studio/space`를 열어 로비 → 캐릭터 선택 → 입장 → 패널 → 3D 전환 순서로 직접 조작했다.
- HUD 요소(위치 칩, 공정 바, 지도, 상태 칩, 패널, 도크, 줌, 조이스틱, 3D 칩)의 사각형을 읽어 서로 겹치는지 자동으로 비교하는 점검 스크립트를 만들어 여러 화면 폭과 패널 열림·닫힘, 서비스 상태 칩 유무에서 실행했다.
- 패널 각 탭을 열어 가로 넘침, 잘린 글자, 터치 목표 크기, 이름 없는 컨트롤을 스캔했다.
- 작화 6종은 모두 순환하며 가로 넘침과 콘솔 오류를 확인했다(오류 없음). 공간 테마 13종은 목록과 선택 상태, 카드 정렬을 확인했고 일부 월드 화면만 눈으로 봤다.

## 검증

- 단위·계약 시험을 새로 추가했고 수정 전 코드에서 실패(11건)하는 것을 확인했다: 공정 바 접근성 이름, 공간 지도 이동 이름, 조명 설명, 요청 토스트, NPC 안내, 공정 바 CSS 배치 계약, 3D 칩 배치 계약, 순간 이동 막 세기·소멸·동작 줄이기·그리기, 작화 안내 범위.
- 영향 범위 시험: `virtual-space/hud`, `virtual-space/office2d`, `virtual-space/three`, 로비·선택기·테마 선택기·환경 패널 등 관련 파일이 통과했다.
- 브라우저 측정: 1024/1280/1440/1600/1920px(패널 열림·닫힘), 390px 모바일에서 HUD 겹침 0건을 확인했다. 3D 칩은 1280px에서 줌 바와 6px 간격, 모바일에서 도크와 겹침 없음.
- 순간 이동 막은 캔버스 평균 밝기를 프레임 단위로 읽어 340ms 안에 원래 밝기로 돌아오는 것을 확인했다.

## 남은 범위(미확인·미수정)

- 1024~1319px에서 패널이 열린 상태는 공정 바 도구 버튼(협업창·내 자리·평면도·공간음)이 가로 스크롤 끝에 있다. 스크롤 힌트(가장자리 페이드)는 아직 없다.
- 공간 테마 13종과 일러스트 쇼케이스 12종의 월드별 충돌·좌석·애니메이션은 전수 확인하지 못했다.
- 실제 두 기기 통화, 화면 공유, 서버 동기화는 API가 없는 로컬에서 확인하지 못했다.
- 이동 가속(1900px/s²)·감속(2600px/s²)은 손대지 않았다. 순간 이동 전환만 추가했다.
- 지도 라벨은 세밀한 월드 아트 위에 겹쳐 있어 작은 구역에서 읽기 어렵다. 후속 디자인 과제로 남긴다.
