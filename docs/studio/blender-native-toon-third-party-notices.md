# 자체 웹 툰 runtime의 제3자 고지

상태: **current**. 2026-10-29 소스 기준이다.
`@pixiv/three-vrm` 3.5.5의 공개 MToon API와 수식을 사용하는 adapter, animated UV 보정과 lighting model은
원래의 MIT 저작권·허가 고지를 유지한다. Three 0.186.1의 공개 ShaderChunk 깊이 packing을 TSL로 표현한 helper도
아래 고지를 따른다. 라이선스 원문은 정확한 보존을 위해 영어로 기록한다.
