# 가상 스튜디오 테마·캐릭터 검수 — 2026-11-03

상태: current. 클라우드 개발 환경에서 확인한 범위와 후속 제안이다. 전체 기능 검수 완료를 의미하지 않는다. 운영 배포와 유료 자산 구매는 하지 않았다.

## 현재 구조와 재현 결과

- 진입: `/studio/space`, 팀 작업실: `/studio/p/:projectId/space`.
- 기본 렌더러는 `office2d`, 선택형은 `three`, 이전 Phaser는 `?stage=legacy`다.
- 작화 6종, 공간 팔레트 13종, 일러스트 쇼케이스 12종, 3D 공간 9종은 서로 다른 카탈로그다. 숫자를 합쳐 하나의 테마 수로 안내하면 실제 선택 결과를 오해할 수 있다.
- 실제 브라우저에서 로비 → 하늘 선택 → 선택하고 입장 → 개인 작업실 진입을 확인했다. 최초 개발 서버 컴파일·로딩은 15초 안에 끝나지 않았으나 워밍 후 45초 대기에서 로비를 확인했다. 서버 협업 기능은 API가 없는 클라우드 개발 상태라 연결 중으로 표시됐다.
- 기본 2D에서 하늘을 고르면 월드는 별도 직군 스프라이트로 재배정하지만 도크는 원래 분홍 머리 캐릭터를 표시했다. 수정 후 도크·내 카드·근접 카드·같이 작업하기 목록은 월드의 `office2dCharacterForAvatarSkin`과 동일 atlas의 정지 프레임을 사용한다.
- Phaser 경로의 상태창에는 선택 작화 전달이 빠져 있었다. 기존 `studioCharacterSkinForArtStyle`을 재사용해 6종 작화와 같은 자산을 쓴다. 직접 선택한 네이티브 테마 캐릭터·LPC 원본은 보존한다.
- 공간 테마 카드는 추천 레지스트리와 무관한 별도 캐스트 이미지를 사용했다. 실제 추천 목록 첫 캐릭터의 스프라이트와 추천 이름 2개를 표시하도록 바꿨다. 카드 선택으로 캐릭터를 강제 변경하지 않는다.

## 검증 방법과 한계

- 독립 화면: `/tools/browser-harnesses/virtual-studio-character-consistency.html`. 실제 캐릭터 선택창·상태창·테마 선택 컴포넌트를 사용한다. 합성 문서나 서버 인증을 실제 작업으로 가장하지 않는다.

- 단위 검증: 6종 작화의 기본·집중·검수 자산, 네이티브·LPC 유지, 모든 선택 캐릭터의 office2d 직군·atlas 프레임, 13종 추천 UI, NPC 초상화 기존 계약.

- 전체 경로의 모바일, contrast, 3D 전환, 네트워크 협업, NPC별 대화, 모든 테마의 월드 반영은 별도 검증이 필요하다. 독립 화면의 성공을 전체 앱 성공으로 확대하지 않는다.

## 업무·회의·사운드·키보드 읽기 전용 조사

추가 요구에 따라 이 절은 조사·후속 제안만 기록한다. 회의·음원·입력 처리는 이번 PR에서 변경하지 않았다.

### 현재 코드에서 확인한 사실

- `StudioVirtualSpaceAmbientAudio.tsx`: 환경음은 기본 off, 사용자가 켜야 재생한다. 환경음과 효과음 볼륨·켜짐은 별도다. 회의 오디오 포커스를 구독해 환경음 gain을 15%로 낮춘다. 집중·자리 비움·탭 숨김·창 blur 때 일시 중지한다. 통화 송출과 혼합하지 않는다고 UI가 안내한다.
- 환경음 카탈로그는 녹음 빗소리 2종과 바람·실내 공기·파도·난로·집중 시냇물·정원 바람 합성 6종이다. 테마 음악 자동 연결은 이 카탈로그에 없다. 실제 음악·대화 동시 청음은 미검증이다.
- `studio-virtual-space-sound-preference.ts`: 공통 효과음은 기본 켜짐, 볼륨 70%다. 발걸음·상호작용·입퇴장 등은 환경음과 별도 엔진이다. 환경음 ducking 구독이 효과음에도 적용되는지는 확인되지 않았다.
- 기본 2D는 `office2d-stage-extensions.ts`의 별도 음소거 저장 키와 WebAudio cue를 쓴다. `talking`이면 cue gain을 25%로 낮출 수 있으나, 확인한 `StudioOffice2dCanvas.tsx`의 입장·착석·책상·이모트 호출은 `talking`을 전달하지 않는다. 따라서 구현 주석만으로 회의 중 자동 감쇠가 동작한다고 볼 수 없다.
- `StudioOffice2dCanvas.tsx`: 이동 키는 포커스 소유권을 확인하고 보조키·IME 조합을 거른다. keyup과 blur에서 이동 상태를 해제한다. `use-space-shortcuts.ts`는 input/textarea/select/contenteditable/role=textbox 입력, IME, 이미 처리된 이벤트를 제외하며 Enter는 버튼·링크 기본 동작을 존중한다.
- H는 HUD의 내 자리 단축키와 Canvas의 내 자리 처리 양쪽에 있다. 실제 중복 실행 여부는 이벤트 전달 순서와 포커스에 따라 재현해야 한다. 현재 조사만으로 중복 버그라고 단정하지 않는다.

### 공개 서비스에서 참고한 동작

- WorkAdventure는 대화 중 맵 음악·효과음 볼륨 감소, 환경음·음악 차단, 출력 장치 선택을 제공한다. ToonStudio에도 하나의 소리 패널에서 통화와 배경 소리의 차이를 명확히 보여 주는 방향이 적합하다. [공식 설정 문서](https://docs.workadventu.re/user/settings/)
- WorkAdventure는 Do not disturb·무음 구역·회의실에서 대부분의 알림음을 억제한다. 업무 모드에서는 게임성 효과보다 회의·집중 상태를 우선하는 정책을 참고할 수 있다. [공식 알림 문서](https://docs.workadventu.re/user/notifications/)
- Gather는 주변 대화 전체/개별 음소거와 Busy 상태를 통한 방해 감소를 안내한다. ToonStudio의 조용히 모드는 이름만으로 실제 들리는 범위를 오해하지 않게 설명할 필요가 있다. [공식 시작 안내](https://support.help.gather.town/articles/1982412443-getting-started-guide)
