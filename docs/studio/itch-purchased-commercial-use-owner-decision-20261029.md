# itch.io 구매 번들의 ToonStudio 상업적 프로젝트 활용 결정

상태: **migration**. 2026-10-29 소유자 지시를 권리 원장과 소비 경로에 반영하는 기록이다. 구현·검증·배포 완료를 뜻하지 않는다.

## 결정과 적용 범위

2026-10-29 소유자는 구매 번들에 관해 “직접 구매한거라 상업적으로 사용해도 된다.”고 확인하고, “일단, 최대한 사용하고 나중에 물어봐 정 물어보고 싶으면”이라고 지시했다. ToonStudio의 2D 작업과 3D 가상 스튜디오에 구매 자산을 최대한 활용하고 제작사 문의는 후순위로 둔다. 같은 날짜의 “운영 배포까지 진행해줘” 지시에 따라 구현·정상 검증·main 병합 후 운영 반영까지 진행한다. 배포에는 기존 승인 SHA·CI·산출물·롤백 절차를 적용한다.

원장의 `owner-commercial-use-confirmation`은 구매자인 소유자의 확인을 기록한다. 제작사가 새로 회신한 허가나 CC0 증빙으로 표시하지 않는다. 범위 식별자는 `toonstudio-in-service-commercial-project-use`이며, 서비스 안에서 장면·테마·작업 결과를 구성하는 상업적 프로젝트 이용에 적용한다. 이번 변경은 원본 팩의 단독 재판매·다운로드 기능을 추가하지 않는다.

## 원장과 출처 보존

- 기존 CC0 증빙이 있는 팩은 그 분류와 증빙을 유지한다.
- 소유자 확인으로 편입하는 구매 팩은 `licensed`로 기록하고 `commercialUse: true`를 사용한다. 원래 `licenseClass`, 제작자, 구매 URL 연결, 라이선스 원문·해시·출처 경로를 보존한다.
- 확인은 현재 팩 ID, 같은 팩에 연결된 구매 확인 참조, 이 문서, 확인일 `2026-10-29`에 결합한다. 다른 팩의 구매 기록이나 일반 검색 결과만으로 구매 확인을 대체하지 않는다.
- 원문의 출처 표기 의무와 실제 표기문을 보존한다. 표기문이 필요한 팩은 공개 카탈로그에서 검증 레코드와 장면 출처까지 같은 값을 전달한다.
- 원본 master와 웹 파생본은 구분한다. 모델·재질·UV·skin·애니메이션 보존 여부와 실제 렌더 검증을 상업 이용 확인으로 대체하지 않는다.

기존의 ‘제작사 추가 답변 부재’를 구매 자산의 상업적 프로젝트 이용을 일괄 보류하는 이유로 사용하지 않는다. 팩 ID 중복·인제스션 귀속·지원 형식·원본과 파생본 연결·실제 배포 바이트가 미확정인 항목은 기술 편입 상태로 기록한다. 준비 중이라는 표기를 상업 이용 불가 판정으로 바꾸지 않는다.

## 검증과 운영 반영

권리 원장 검사, 공개 투영과 웹 소비자의 회귀 검사, 2D/3D 저장 분리, 실제 자산 디코드·표시·출처 보존, 빌드·운영 스모크를 각 단계의 정확한 소스와 SHA에 연결한다. 모든 구매 팩이 이미 다운로드·변환·서비스 편입됐다고 간주하지 않는다. 검증 실패는 수정 후 해당 범위를 다시 확인하며 정상 hook과 보호 규칙을 유지한다.

제작사 연락 초안은 참고 자료로 남긴다. 현재 지시에는 외부 문의 발송이 포함되지 않는다.
